# 基因与蛋白

检索词：UniProt、Ensembl、NCBI、OpenTargets、Reactome。先固定物种、参考基因组和标识符命名空间；基因符号不能代替稳定 accession。保留映射的一对多关系、版本、同工型与未匹配项。

已知蛋白可搜索 `UniProt accession`，describe `tooluniverse.tool.UniProt_get_entry_by_accession`；P05067 为示例 accession。功能注释、通路和靶点证据分别检索并注明来源，关联强度不能直接解释为因果。表达矩阵及单细胞分析继续交给 OmicVerse；既有 Biomni 数据湖与专项工具保留原路由。

固定上游的相关研究任务可按需从[工作流导航](upstream/genes-proteins.md)选择。每个摘要保留原文链接、摘要 SHA-256、阶段结构和固定 SDK 工具候选，执行仍以实时 schema 为准。
