# 分析场景

所有分析先检查服务端状态和实时输入 schema。下面的入口仅帮助选择分析方向，具体入组规则、分母和输出以所选 Fun 的源码与实际 Manifest 为准。

## 单药信号筛查

使用 `AFun` 研究指定药物与 FAERS 不良事件的比例失衡，按研究方案限定报告期、人群和药物角色。核对数据库实际药名和覆盖期；不要把报告比例解释成发生率或风险大小。

## 药物与目标事件

使用 `CFun` 评估指定药物与 MedDRA PT 的比例失衡；使用 `BFun_upgrade2` 可在目标 PT 上进一步限定药物。核对 PT 的准确首选术语，并说明按报告还是药物-事件对计数。

## 联合暴露

`DDI`、`DDIALL` 与 `Concomitant_Medication_Analysis` 使用不同的联合/单药队列定义。先明确首要怀疑药、联用药及 PS/SS/C/I 角色，再据实时 schema 选择入口。不要把不同入口的队列口径合并解释。

## 候选药物对比

`disproportionality_analysis_for_top50_drug` 可在同一目标 PT 上比较最多 10 个明确提供的候选药。先给定有来源的候选集；函数名中的 top50 不会自动检索或生成候选药物。
