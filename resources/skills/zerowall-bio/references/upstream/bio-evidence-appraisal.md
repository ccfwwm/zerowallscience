# 证据分级与结论强度（Evidence Appraisal）

> 吸收自 [aipoch/medical-research-skills](https://github.com/aipoch/medical-research-skills)（MIT，commit `f5ef65b9`）的
> `evidence-level-ranker` + `scientific-critical-thinking` 知识层，已改造为分子生物学/合成生物学口径。
> 全部书目锚点经 PubMed 实测核验（见 §8），非记忆引用。

## When to Use

- 判断一批文献里**哪些证据更强、该引哪篇**作锚定引用
- 已有结论（自己的或文献的）要判断**「能说多强」**——写讨论/结论/摘要前
- 系统综述的偏倚评估与 GRADE 评级（流程侧见 `bio-literature-review`）
- 复盘一个分析结论是否越界（配 `dsh-bio-genie-guide-rigor` 使用）

## 0. 与溯源分级的分工（先分清两层，别混用）

| 层 | 回答的问题 | 在哪 |
|---|---|---|
| 溯源分级 A–E | 这个**数字**从哪来（工具输出/注释/文献/推测/假设） | `guide-rigor` §1b |
| 结论强度分级（本 skill） | 这个**结论**能说多强（设计/执行/验证深度/表述纪律） | 本 skill |

两层独立。一个数字可以是 A 级（工具实测），但它支撑的生物学结论仍可能很弱（n=1、无重复、无正交验证）。

## 1. 证据层级（按「设计能排除偏倚的程度」排序，不是按声望）

**人群/临床类七级**：

| 级 | 设计 | 关键局限 |
|---|---|---|
| L1 | 系统综述 / Meta 分析（同质且无严重偏倚） | 纳入研究同样偏倚 = garbage in |
| L2 | 随机对照试验（RCT） | 执行差（不盲、失访高）时实际强度骤降 |
| L3 | 队列研究（前瞻 > 回顾） | 混杂残留 |
| L4 | 病例对照 | 选择偏倚、暴露回忆偏倚 |
| L5 | 横断面 | 只能报告关联 |
| L6 | 病例系列 / 个案 | 无对照 |
| L7 | 专家意见 / 机制推论 | 未被数据检验 |

**基础与计算研究梯级**（无人群设计时用这一套）：

| 级 | 证据形态 |
|---|---|
| B1 | 独立重复 + 正交方法 + 定量剂量-效应关系 |
| B2 | 单研究内多方法交叉验证（如敲除 + 回补 + 酶活 + 表型一致） |
| B3 | 单方法单模型（仅体外酶活 / 仅一个菌株 / 单一组学层） |
| B4 | 相关性 / 组学发现（无任何功能验证） |
| B5 | 计算预测（结构预测、docking、网络推断、FBA）——**默认此级，除非有实验正交验证** |

**两个反直觉细则（必须显式检查）**：

- **低层级可以很强**：决定性机制证据（直接体外重建某反应）、效应极端且可重复、剂量-反应关系成立 —— 不要因为"不是 RCT/不是多组学"就贬低。
- **高层级可以很弱**：RCT 但盲法/失访有问题；Meta 分析纳入研究同源偏倚；大样本但测量工具无效 —— **设计标签 ≠ 真实证据价值**。

## 2. GRADE：把「质量」拆成四档 + 五个降级域

对**每个结局分别**定档：`High / Moderate / Low / Very low`（RCT 起始 High，观察性研究起始 Low，再按下面调整）。

**降级五域**（任一严重降 1 档，非常严重降 2 档）：

1. **Risk of bias** 偏倚风险（随机化/盲法/失访/选择性报告）
2. **Inconsistency** 异质性不可解释（I²、点估计方向不一致）
3. **Indirectness** 间接性（人群/干预/结局/对照与问题不匹配）
4. **Imprecision** 不精确（置信区间宽、事件数太少）
5. **Publication bias** 发表偏倚（小样本研究扎堆、漏斗图不对称）

**升级三因素**：效应量极大 / 剂量-反应关系 / 反向混杂只会削弱效应（plausible confounding would reduce the effect）。

**报告用语映射**：High≈「确证」；Moderate≈「很可能」；Low≈「可能」；Very low≈「不确定」——**Very low 不得写成结论句**，只能写成"目前证据不足以判断"。

## 3. 四轴评估（判断一批论文或一个结论的实操框架）

| 轴 | 内容 | 要点 |
|---|---|---|
| ① 证据家族 | 真正的设计（读 Methods，不采信作者自称/期刊栏目） | 别把数据来源、检测平台当成研究设计 |
| ② 执行质量 | 抽样逻辑、偏倚控制、样本量 vs 分析复杂度、结局定义、统计纪律、缺失数据处理、可重复性 | **禁止用 p 值或效应量大小反推方法可靠** |
| ③ 验证深度 | 见下方阶梯 | 同一数据集反复分析 ≠ 独立验证 |
| ④ 表述纪律 | 结论是否越界 | 见下方五型越界 |

**验证深度阶梯**（左弱右强）：无验证 < 内部重采样（交叉验证/bootstrap）< 独立留出/外部队列 < **正交方法**（不同原理的实验交叉确认）< 独立重复（不同实验室/不同菌株背景）< 前瞻性/实施级验证。

> 生信映射：交叉验证 < 同数据 held-out < 独立数据集 < **湿实验正交验证预测** < 独立实验室复现。
> 只做到前一档，就不能用后一档的措辞。

**表述越界五型**（发现即降引用权重/降措辞）：

1. 关联说成因果（"相关"→"驱动"）
2. 回顾性/模型性能说成应用价值（AUC 0.9 ≠ 可用）
3. 探索性标志物说成已确立标志物
4. 机制信号说成工程/治疗学证明
5. 亚组/事后结果说成普适结论

## 4. 引用角色（给每篇定角色，而不是笼统排序）

| 角色 | 用于 |
|---|---|
| **锚定引用** Anchor | 支撑中心主张的最强证据（通常 ≤2 篇，多了等于没有锚） |
| 高价值支持 | 强支持但非唯一最佳 |
| 背景/上下文引用 | 铺垫领域现状，不承担论证 |
| 机制支持引用 | 提供生物学合理性，**不支撑因果或应用结论** |
| 谨慎引用 Caution | 仅在显式写出其局限时引用 |

**输出骨架**（评估一批文献时）：比较目的 → 每篇真实设计 → 执行质量 → 验证深度 → 表述纪律 → 排序 + 理由 → 不确定性。
混合证据家族时**不许坍缩成单一分数**：说明比较逻辑，并注明哪些论文服务不同证据角色。

## 5. 措辞边界表（写作时对照）

| 证据状况 | 能说 | 不能说 |
|---|---|---|
| 单一计算预测（B5） | 「预测…（尚无实验验证）」 | 「已证明」「已确定」 |
| 相关性/组学关联（B4） | 「与…相关」「富集于…」 | 「导致」「驱动」 |
| 单方法单模型（B3） | 「在本实验条件下观察到…」 | 「普遍存在」「该物种通性」 |
| 无重复 n=1 / 单批次 | 「提示」 | 「表明」「证明」 |
| 模型输出（FBA/ML/结构预测） | 「模型预测…（模型假设：…）」 | 「细胞实际会…」 |
| 缺独立验证 | 「需独立数据/实验验证」 | 「已确立」 |

## 6. 硬规则（违反即返工）

1. 不按期刊声望、引用数或叙述自信度排序证据。
2. p<0.05 ≠ 方法可靠；显著 ≠ 重要（必须看效应量）。
3. 不把探索性、事后、亚组结果当确立证据。
4. **PMID/DOI/注册号必须来自检索核验**（`bio_pubmed_search` / `bio_entrez_search`）；无法核验的一律标 `[未核验]`，**禁止凭记忆补全**。
5. 不虚构样本量、事件数、效应估计、验证队列、数据可获得性。
6. 论文服务不同证据角色时显式说明，不强行压成一维排名。
7. 只用「四轴 + 措辞表」得出的结论才算评估完成；只给排序不给推理 = 未完成。

## 7. 计算配方（I²、τ²、κ）

```python
import numpy as np

def i_squared(Q, k):
    """异质性 I²（%）：Q 来自 Cochran Q 检验，k = 研究数。
    解读阈值（Higgins 2003）：25% 低 / 50% 中 / 75% 高。"""
    if k <= 1 or Q <= 0:
        return 0.0
    return max(0.0, (Q - (k - 1)) / Q) * 100.0

def tau_squared_dl(wi, yi):
    """DerSimonian-Laird τ² 估计。wi = 各研究权重(1/vi)，yi = 效应量。"""
    wi = np.asarray(wi, dtype=float); yi = np.asarray(yi, dtype=float)
    sw, sw2 = wi.sum(), (wi**2).sum()
    ybar = (wi * yi).sum() / sw
    Q = float((wi * (yi - ybar) ** 2).sum())
    k = len(yi)
    if k <= 1 or Q <= k - 1:
        return 0.0
    C = sw - sw2 / sw
    return max(0.0, (Q - (k - 1)) / C)

def cohen_kappa(a, b, c, d):
    """两名筛选者的一致性 κ。a/b/c/d = TP/FP/FN/TN（纳入/排除的 2x2）。
    κ ≥0.8 强一致；0.6-0.8 中等；<0.4 需仲裁。"""
    n = a + b + c + d
    po = (a + d) / n
    pe = ((a + b) * (a + c) + (c + d) * (b + d)) / n**2
    return (po - pe) / (1 - pe) if pe != 1 else 1.0
```

## 验收标准

- [ ] 每个结论标齐**四轴**（证据家族 / 执行质量 / 验证深度 / 表述纪律）
- [ ] GRADE 档位是在**五个降级域**逐一评估后给出的；Very low 未写成结论句
- [ ] 全部 PMID/DOI 来自检索核验，无法核验的标 `[未核验]`
- [ ] 措辞与证据强度一致（对照 §5 措辞边界表）
- [ ] 混合证据家族时说明了比较逻辑，未坍缩为单一分数
- [ ] 验证深度用语未越档（如仅交叉验证却写"已独立验证"）
