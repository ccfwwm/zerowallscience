Use the compact MCP entries `r_runtime`, `r_project`, `r_files`, `r_execute`, `r_jobs`, and `r_packages` for general R computation and project management. Validate project and file paths before execution. Workspace uploads require `r_files` with the upload action and confirmation. Prefer bounded outputs, pagination, and saved artifact references so large tables do not enter the chat context. Inspect the available R tool schemas and runtime catalog before executing an unfamiliar action.
