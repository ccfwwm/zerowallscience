# @zerowallscience/plugin-videos — 多媒体创作

0.2.8：提交前清理提示词中的编号素材引用（包括图片、视频、音频和参考素材写法），保留素材数组、顺序及其他参数；媒体工作台显示视频任务创建时间并按最新任务优先排列。若当前对话存在未结束媒体任务，通过用户提问窗口确认继续提交或取消；取消或无法确认时不提交，会话级 Host 队列防止并发漏检。

0.2.7：普通参考不再由界面自动补 `role: reference`，保留用户明确的角色及扩展属性。供应商格式转换交给 Sub2API 协议模板；V6K 字符串图片参考可由模板精确过滤普通角色，首尾帧保护仍有效。新增只读联调脚本 `knowledge/media-create/inspect_request.py`，技能与工具说明同步统一接口、参数和原任务查询规则。未修改 ai-cloud 序列化或升其版本。

用户明确要求生成视频、音频/音乐或宣传片时，通过聊天描述需求即可创作。右侧原生工作台用于模型设置、进度与作品预览，无需填写项目表单。支持异步恢复、参考素材导入，以及带字幕、音乐和导入旁白的宣传片合成。图片在此仅作为视频参考素材；普通生图、改图、海报、插画和文档配图统一使用 `gpt-image-generator` 的 `generate_image` / `edit_image`，沿用环境配置的生图模型、分组和参数。配音模型未提供时显示暂不可用。

登录 AI 云平台自动发现“图片音频视频分组”，凭据留在 Host。每次新建或明确重试前读取最近一次已完成的能力目录，目录更新由模型列表同步操作显式触发，避免生成请求造成上游模型发现限流。仅在同分组、同模型、同操作存在唯一当前 profile 时更新过期 profile，保留原参数和参考素材。选择失效或候选不唯一时要求重新选择，不擅自换模型。不会修改聊天模型、协议或推理参数。模型工具支持视频和音乐的准备、生成、素材导入、修改、查询与收集。用户明确要求生成视频或音乐时直接执行，后台校验费用及账号权限；若当前对话已有未结束任务，会先用提问窗口确认是否再提交。讨论方案及修改文案不会提交生成；重复调用沿用原请求。首次未配置模型时自动选可用模型。历史图片任务只保留查询与下载，不再提交生成。

新项目位于 media-projects/<projectId>/。普通聊天保持原布局，媒体工作台可收起。分镜列表可编辑素材、时长、顺序、裁切和字幕；支持图片推进/拉远、音乐音量与淡入淡出、导入旁白、片头片尾。默认导出1080p、30fps、MP4 H.264/AAC。保留原始素材，以实际时长校验成片。

本地合成使用 zerowallPython 固定根和执行租约，需FFmpeg、FFprobe、libass、libx264、AAC；依赖缺失时逐项显示。不会回退到PATH Python或自动下载依赖。

安装、验签、候选 profile 健康、原子激活和回滚由既有资源管理器处理。任务中断后恢复原请求；停止等待不等于服务端取消或退款，状态不确定时显示待核查。历史任务仅允许查询和下载。发布前须验收对应网关与真实模型，插件更新无需重打桌面安装器。

创作者统一使用 `images`、`videos`、`audios` 传入有序素材数组，支持 HTTPS URL、完整 MIME Data URL，以及带附加属性的对象；无需按上游协议改写字段。管理员在网关为模型绑定协议模板，由模板定义素材字段映射、编码方式、对象结构和任务响应解析。模型目录用于提示，不代表上游一定接受某类素材；服务端错误会保留在任务诊断中。身份、费用和网络安全边界继续校验。

兼容入口 `media_job.references_json` 接受有序参考数组，每项仅选 `path`、`attachment_id`、`url` 或 `reference_id` 一个来源。URL 须声明 `media_type`；`reference_id` 复用当前任务摘要的 SHA-256，不向模型返回原始编码或签名地址。旧的 `reference_paths`、`input_attachment_ids` 继续可用，但不能与其他素材清单入口同时传入。图片角色可为 `reference`、`first_frame`、`last_frame`；首尾帧不可混入普通图片参考。兼容的 `parameters_json` 可以继续携带统一素材字段，但不得与顶层字段提供不同内容。

本期不接对象存储、不自动上传素材。用户已有 URL 时直接复用；模型需要 URL 或服务端明确拒绝 Base64 格式时，仅请求缺失素材的公网直链。补地址后建立新请求并保留旧拒绝记录；`invalid_public_profile`、`estimate_configuration_changed`、超时、5xx、断网和已有任务 ID 时保留原身份核查，不自动创建新的付费任务。视频使用 `seconds`（兼容 `duration`），比例使用 `ratio`（兼容 `aspect_ratio`）；统一素材字段为 `images`、`videos`、`audios`，模板负责上游映射。

### 参考素材完整性

通过 `media_job.references_file` 读取工作区 JSON 清单（与 `references_json`、旧参考输入互斥），例如 `source/reference-inputs.json`。清单每项包含 `url`、`media_type`，可带 `role` 与模型模板附加属性。不能仅把目录路径写进 prompt。标准字段与旧参数 JSON 中的同名字段语义相同时合并；内容冲突或字段类型错误会在创建任务前拒绝。

公网 URL 和 Base64/Data URL 的实际发送格式由管理员选择的模型模板决定。插件不根据域名或模型名称猜测协议，也不自动移除可选字段。

估价失败返回 `validation-failed` 草稿及原 ID，素材仍保存。修正参数时复用原任务，省略参考输入会继承项目意图；`[]` 不会清空已有素材，只有用户明确要求无参考创作时才使用 `clear_references`。不得因报错去掉图片或视频、更换模型或重建空参考任务。提交前核对返回的参考数量；准备参数、尝试发送和上游受理是不同状态，历史未记录时不得推断素材已经发送。
