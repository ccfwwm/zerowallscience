# Claude Code conversation header button

English | [中文](guide.zh.md)

## Change

The ZeroWall Claude Code runner removes the conversation header button and its diagnostics panel. Plugin settings provide CLI management, and the conversation mode picker opens Claude Code conversations.

## Migration

1. In Plugins → Claude Code runner, open the configuration to view or manage the CLI.
2. Open a conversation. Confirm that the header button is absent and Claude Code is available in the conversation mode picker.
