# Claude Code 会话顶栏按钮

[English](guide.md) | 中文

## 变更

ZeroWall Claude Code 运行器移除会话顶栏按钮及其诊断面板。插件设置提供 CLI 管理，会话模式选择器可开启 Claude Code 会话。

## 迁移

1. 打开「插件 → Claude Code 运行器」的配置页，查看或管理 CLI。
2. 打开任一会话，确认顶栏按钮已移除，并检查会话模式选择器中仍可选用 Claude Code。
