# ZeroWall Desktop 默认设置

[English](guide.md) | 中文

## 变更

账户提供 `gpt-6.2-sol` 时，原有 DeepSeek 或空白默认值改为该托管模型与 `xhigh`。保留其他明确选择的模型。推理强度默认优先使用支持的 Xhigh，其次为 High；两者均不支持时保留受支持档位。每次启动异步刷新 models.dev，失败时保留内置或缓存元数据。

托盘将登录启动操作替换为重启，应用菜单也提供重启。既有启动偏好仍生效。插件更新显示可稍后处理的提示，在后台准备兼容软件包，并在准备完成后提供重启。

应用升级后，较新的随包业务插件优先于白名单中的较旧配置副本。保留的代际不变，较新的独立插件仍覆盖随包版本。Host Runtime 更新位于插件列表。启动时及每天检查更新，侧边栏显示当前版本和更新箭头。

Desktop 9.1.10 打开经过校验的可见 Windows 安装器，确认进程创建后才退出；启动失败时恢复 Host。更新确认遇到 Windows 临时文件占用时会重试并保留原有日志。随包 Host Runtime 使用独立版本 9.1.12，后台准备时持续显示下载、解压和校验阶段。可选内置工作流可通过 `/` 及模型按名称调用；读取有依赖的技能时启动后台准备。科研诚信与 DeepMind 科学研究分别提供插件页面，并保留原有诚信工具。ZeroWall 新会话默认完全权限且无需审批；明确选择的权限仍生效。

## 迁移

1. 安装 Desktop 9.1.10 或配套的 Host Runtime，重启以加载当前 SDK 与插件客户端。
2. 登录后在设置中核对默认模型和强度；如需其他受支持的模型或强度，请明确选择。
3. 从托盘或应用菜单重启；准备就绪后再同意停止活动任务。取消时 Host 继续运行。
4. 在插件 → Skills 独立安装新发布的套装。执行前自动准备缺少的已发布 Python 依赖；失败时查看 Python 设置。
