# ZeroWall Science 7.5.0 发布说明

## 文件预览与 Office

- DOC/DOCX、PPT/PPTX、XLS/XLSX、CSV/TSV 默认使用 DSH 原生查看器，覆盖文件树、聊天附件、历史附件及无工作区附件。
- 通用查看器处理 PDF、图片、媒体、GIS 等其他格式；补齐 SHP、GeoJSON、TopoJSON、KML、KMZ、GPX 的 GIS 插件与侧栏注册，地图样式随包提供。文本、代码、Markdown、HTML 继续使用可编辑入口。
- 修复 Office→PDF 的 Host 适配参数，使用经会话查找解析的工作区上下文，消除 undefined.trim 错误；保留取消、源文件版本校验及有界读取。
- 不支持或超出预览限制的文件显示原因和下载入口。单独 SHP 可预览几何；属性和投影信息需配套文件，在线底图不可用时仍可查看边界。
- 修复 Windows 安装版 LibreOffice 引擎资源与物理路径，解决 Office 转 PDF 的 ENOENT 错误。
- 修复原生 Excel 的重复状态更新导致的白屏，增加 Worker、懒加载、初始化与渲染诊断、重试和查看器切换。
- 查看器资源随包提供，分段读取检查文件版本并支持取消，累计预览上限为 50 MiB。

## 附件解析与提示词

- Host 自动按格式解析 DOCX、PPTX、Excel、CSV 和 TSV；摘要、分页提取结果与原件分别保存。
- 统一原生及旧附件的会话授权、SHA-256 校验与导入；修复并发导入及双解析覆盖元数据的问题。
- MinerU 保留任务 ID，中断后恢复同一任务；无配置、需要 OCR、失败和降级状态明确显示。模型请求失败后复用已完成产物。
- 读取、总结或比较 Office 附件优先使用解析结果，避免误触发 Univer 演示文稿生成。

## 科研 PPT 视觉生成

- 新科研 PPT 默认先生成三张风格样张，自动选择后生成内容种子，再以样张为参考生成独立插图、背景或主题图标。
- 生图模型、质量和尺寸遵循环境配置；用户明确指定的参数仅覆盖当前请求。
- 使用 Univer 排版，正式文字、数据、图表、连接线和布局保持可编辑，生成图像作为独立资源保存。
- 逐页检查、截图和视觉审查；不支持图像输入的聊天模型会收到切换提示。修改已有 PPT 默认保留原图。
- 视觉资源清单记录来源、模型、实际尺寸与哈希，支持恢复失败资产及追踪页面对象。

本版本保留 7.4.0 的 Harness、Zotero、搜索、侧栏与桌面定制。复杂 Office 版面与未逐类验证格式仍受查看器能力限制；详细行为与验证边界见实现及安装包验收报告。
