# ZeroWall Science 5.16.0

## ZeroWall Literature

- 将论文研究固定为 cited-by 流程，不再展开目标论文参考文献。
- 目标论文继续下载并由 MinerU 解析，用于精确识别和检索；引文 PDF 只下载和校验。
- TSG 改为按完整标题优先搜索，失败后继续 paper-download；paper-download 默认启用扩展级联。
- 目标论文和引文 PDF 统一保存到任务根目录的平面 `downloads/` 文件夹。
- PDF 下载与作者、期刊联网检索并行执行，每篇论文使用独立下载工作目录。
- Free Search 显式测试并调用 Bing、Exa、Tavily 等引擎，不再只依赖全局 DeepSeek 配置。
- 只分析引文作者，排除目标论文作者；作者资料包含现职、单位、国家、研究方向、代表论文和荣誉任职。
- `papers.xlsx` 精简为 `引文列表` 和 `作者列表` 两张工作表，内部状态与下载审计移入 `analysis/`。
- 中文离线报告聚焦去重引文数、期刊传播、影响因子、作者国家与机构分布及重点引文作者。
- 所有网络和下载错误统一使用首次尝试后最多 5 次重试的预算。

## 兼容与数据

- 新任务的状态、收据、MinerU 和报告清单统一保存到 `analysis/`。
- 旧任务的历史展示文件迁移到 `analysis/legacy-output/`，不覆盖已有研究数据。
- 影响因子仅在指标值、年份和来源页面齐全时进入 Excel 和报告；其他缺失字段留空。
