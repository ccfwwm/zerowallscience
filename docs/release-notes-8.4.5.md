# ZeroWall Science 8.4.5

- 修复安装暂存阶段持续权限拒绝后无法申请权限继续的问题：完整回滚成功后可申请一次 UAC 授权，沿用原用户、安装目录和安装范围；取消授权仍可选择用户目录或查看日志。
- 安装事务保留逐文件校验、有限重试与完整回滚。文件占用、回滚尚未完成或已提升权限的流程不会循环请求授权，避免覆盖未恢复的安装状态。
- 更新媒体创作插件：统一图片、视频、音频参考输入，支持素材清单与完整 Base64，保留素材顺序、角色及附加属性，失败后保留草稿和素材，显式操作才能清空参考。
- 集成最新已验证插件资源，保留账号、模型、项目、自定义插件、禁用选择和固定版本；不改变用户选择的默认模型。

系统策略、杀毒软件或无法释放的文件锁仍可能阻止写入；安装器将显示真实失败并回滚，不会伪报成功。客户机器上的具体 ACL、杀毒软件与跨用户 UAC 行为仍需现场验证。
