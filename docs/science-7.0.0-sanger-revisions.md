# 7.0.0 Sanger 人工修订

工作台可按原始 1-based 调用位置登记 IUPAC 替换，必须提供旧调用、新调用和依据。原始 AB1/SCF、四色信号、峰位均不修改。ViewerSession 保存带源 SHA-256、前置版本和时间的追加修订历史；并发旧版本、旧调用不一致、重复位置及无依据修订会被拒绝。

修订调用不继承原仪器的 PCON/概率：该位置质量改为未知，默认将概率裁剪设为 0 并明确显示。这意味着修订后恢复完整调用范围，用户必须复核新的序列与裁剪范围。导出保存修订历史和原始哈希，并标记 `needsReview`；不自动授予最终科学主张认可。

碱基修改在同一 Store 事务中使该视图的旧产物、通过 `sourceArtifactIds` 引用的图表、关联证据与主张进入待复核，研究门禁二回到 pending。未修订的原始源仍可核验。双向核对还拒绝两个视图引用完全相同的源 SHA-256，避免把同一次测序重复打开当作两个读段。

验收：12 项 Sanger 契约/Host/UI 测试；真实公开 3100 AB1 经 React→Host→导出→重开恢复链路通过。证据 `.build/sanger-revision-viewer-smoke/2026-09-22T06-25-50.714Z/report.json`，刻意将第 100 位修订为 R，用于软件验证，不是生物变异判断。该源此前已有独立 Biopython 1.88 全通道/峰位/质量比较。

本轮只提供人工替换和审计，不自动推断混合峰比例或杂合变异，也不插入/删除原始调用。最终人工测序复核仍需真实正反向实验信息。
