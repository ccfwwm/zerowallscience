# ZeroWall Science 8.0.8

8.0.8 恢复 8.0.6 的完整默认科研桌面。Core 保持独立，安装器另外携带完整默认插件的签名离线依赖闭包、独立插件包、默认 Skills 和小型 MCP 运行资源；首次激活不需要从 npm 或远端目录下载插件。
