# ZeroWall Science 8.0.5

## Python 环境与依赖

- 修复 Python 英文界面中的任务阶段和基础依赖错误仍显示中文的问题。
- 明确区分仅含 Python 与 pip 的 bootstrap 和后台自动安装的 42 个核心依赖；科研与生信依赖仍由用户选择后按需安装。
- 将 Python + pip bootstrap 独立资源升级到 `1.5.1`，科研/生信清单升级为 `3.12.10-r15`；桌面默认入口与签名发布器同步指向新资源，仍在启动后下载，不增加安装包体积。
- 保留可恢复的后台任务、实时进度与日志，以及失败后逐包处理和重试能力。
- 新增资源签名信任根 `stable-4`，同时继续信任 `stable-3`，用于发布新的插件、Skills、MCP 和 Python 资源目录。

## 其他修复

- 合并 8.0.4 开发线上的 RMCP 工具发现、Python 命令行、历史会话兼容和升级修复。
- 更新 `plugin-base` 至 `0.1.5`、`plugin-mcp` 至 `0.2.2`，以便单独更新对应修复。
- 更新 `plugin-research` 至 `0.1.2`，使其发布版本准确包含最新共享研究界面代码。

桌面版本为 `8.0.5`。安装和资源更新仍由用户明确发起；启动检查不会自动安装插件、Skills 或 MCP 资源。
