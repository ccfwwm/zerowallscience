# ZeroWall Science 7.0.4

发布日期：2026-09-24。

7.0.4 汇总 7.0.0 以来的科研工作台、受管理 Python 环境和桌面运行时改进。Windows x64 安装包已完成本地构建和验收。

## 7.0.0 科研工作台

- 新增研究概览、数据与资料、研究计划、专业工具、证据与结论、报告与评估六个工作区页面；专业工具按需打开并保留会话中的视图状态。
- 增加持久研究问题、数据契约、方案冻结与修订、证据和主张记录，区分计算成功、科学适用性和人工认可，并保留科研门禁。
- 支持 H5AD 细胞查看、基因表达、质量控制、圈选和导出，并完成十万细胞级性能验证。
- 支持受限 TIFF、OME-TIFF 和 OME-Zarr 查看、轴位置选择、原像素 ROI 测量、分块读取，以及本地 Fiji/napari 打开、标注回传和冲突保留。
- 增加 Western blot、划痕、克隆、菌落和成管五类 Fiji 实验的固定执行路径、质控叠加和可追踪产物。
- 增加 OpenSlide 金字塔 HE 查看、物理测量、区域导出和 CPU 分块分割入口。
- 增加 Mol* 分子结构查看，支持 PDB、mmCIF、SDF、测距、表面和截图导出，并保留 Vina 对接流程。
- 增加 FASTA/GenBank 序列图谱与注释、限定 PCR/Gibson/Golden Gate 模拟、AB1/SCF 峰图和参考比对、FCS 分块处理与限定 GatingML 2.0 交换。
- 增加 1 至 9 面板科研画布、轴/图例/配色编辑和 SVG、PNG、PDF 导出，以及 BrainGlobe 工作流入口。
- 改进 NHANES 数据契约和权重校验，接入固定遗传分析与组学工作流；研究记录包含系统提示词、角色规范、技能来源和策略哈希。
- 统一 Windows Host 的 Sharp 版本，修复混用 libvips 导致的分子截图导出失败；补充图像强度、标签掩膜、OME 轴和 FlowJo 有界批处理工作流。

## 7.0.1 工具与引擎中心

- 新增顶部工具标签工作区，助手栏与中央专业视图联动；对话和 Agent 可以打开工具、聚焦资产、跟踪任务并接收进度和产物事件。
- 事件按 session 持久化，支持去重、断线游标恢复和幂等请求。
- 新增 Fiji/ImageJ、napari、HE、BrainGlobe 和远程 R 的路径、环境、版本与诊断配置。
- Fiji 支持默认路径探测、用户覆盖和真实 bundled Java 探测；引擎未配置或无效时明确显示状态，不伪造为可用。

## 7.0.2 主题与基础运行时

- 工作台和工具界面改为自包含主题，修复宿主主题变量缺失造成的白底黑字退化。
- 保留对话与 Agent 的工具联动，支持工作区标签、资产、任务和产物回写。
- Python 科研环境拆分基础运行时与按需依赖清单，并修复 Windows TLS CA 路径注入。
- 通用首页不再默认展示特定肥胖—脱发案例，平台评估接口仍然保留。

## 7.0.3 共享 Python 与工作台运行时

- 将 Python 作为 MCP、科研工具和 Agent 共用的受管理运行环境，支持旧环境迁移、依赖预览、用户确认后同步、失败恢复和真实健康检查。
- 依赖安装统一进入共享 `Python/Lib/site-packages`，用户包保留；签名清单、锁定版本和 SHA-256 校验保护依赖来源。
- 支持从源码构建缺少 Windows wheel 的包，修复嵌入式 Python `._pth` 对构建子进程的影响，并统一 Python、pip、MCP 的证书路径和连接诊断。
- Python 设置页重做为紧凑状态、共享路径、依赖计划、包搜索和高级诊断；`python_environment` 提供状态、同步预览、确认应用、设置、诊断和回滚接口。
- Science Workbench 改为主标签页结构，常用工具固定在标签栏，其余工具收纳到“更多工具”；引擎设置按项目、用户、环境变量、自动发现和默认值解析。

## 7.0.4 稳定安装与科研文件修复

- 首次启动自动准备安装包内的签名 Python 基础环境并显示下载、解压、校验和安装进度。
- Python 运行目录固定为 `%APPDATA%\zerowall-science\Python`，依赖直接安装到 `Lib\site-packages`；旧版 Junction、活动环境和无效精简状态可迁移到真实稳定目录，不再为普通依赖更新创建 `local-*` 快照。
- 修复 `ZeroWall Python manifest identity or target is invalid`，并修复安装成功后重复提示同一批依赖的问题。安装后会重新扫描包、刷新运行时元数据和待同步状态，并明确显示成功、部分成功、失败或无需安装。
- 默认 Python 镜像改为中科大，镜像下拉列表包含阿里云、清华、中科大、腾讯、华为、官方 PyPI 和自定义镜像。断流、超时、连接中断和 5xx 会清理损坏文件、按同一镜像退避重试并重新校验长度和 SHA-256。
- 精简 Python 环境页面，常用区只保留镜像、刷新、同步、路径复制、打开目录、状态和进度；包搜索、单包维护、预览、回滚、自定义镜像和详细诊断移入高级设置。
- 修复科研工作台“选择文件”无响应。现在可选择项目外文件，复制到项目 `.zerowall/imports/`，校验类型、大小、完整性和 SHA-256，登记为项目资产并自动选中查看。
- 按文件类型自动进入 ImageJ 图像、HE 切片、序列、Sanger 或分子查看器；“打开图像”和“打开切片”真实调用 `image_open` / `he_open`，未配置引擎或未选择资产时给出明确状态。

## 验收与发布范围

- Windows x64 安装包：`zerowall-science-7.0.4-win-x64.exe`。
- 本地构建、桌面启动、Host、Python 首次安装与稳定目录、依赖同步、科研文件导入和查看器回归测试均已完成；具体大小、SHA-256 和公网发布校验记录在 `docs/release-verification-7.0.4.md`。
- 依赖清单中的科学包仍按需同步；Fiji、napari、HE 等外部引擎由用户配置并保留各自的可用性状态。
