# ZeroWall Science 6.0.3

## Highlights

- Added `dsh-progressive-tools` 0.4.0 in stable-proxy mode to keep the model's top-level tool surface stable while discovering tools on demand.
- Added request cache diagnostics with tool schema, system prompt, skill, route and dynamic-context fingerprints.
- Added the session notification plugin to the bundled runtime.
- Retained the default light theme without a background image.

## Compatibility

- Windows x64 desktop package.
- DeepSeek Harness `0.1.5-rc.2`.
