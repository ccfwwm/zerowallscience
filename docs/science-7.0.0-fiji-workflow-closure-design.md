## 2. 最小闭环：先复用修订，再关联序列，最后持久队列

### A. 单资产接受的标注/掩膜修订

复用 `AnnotationRevision` 和已有图像注释业务服务。提交时冻结 `sourceAssetId + sourceSha256 + annotationRevisionId + maskArtifactId/hash + runnerHash + parameters`。不接受裸路径、聊天中的“已校正”描述或其他项目的掩膜。ROI/掩膜必须记录源尺寸、轴、坐标变换、像素间距；读取后校验位深和尺寸。裁剪局部掩膜必须带原始像素偏移，不可静默 resize。

最小输入支持：一个分析区、一张显式 exclusion mask，以及可选已审核 binary mask。先生成自动掩膜，再以 exclusion 清除不可评估区域；最终接受的手工掩膜是新产物，不覆盖原图/自动掩膜。变更内容记录操作者、原因、父 revision、源哈希和时间。

人工闭环：显示源图/自动掩膜/排除区/接受掩膜 → 编辑或原生导入 → 验证并生成修订 → 明确接受修订 → 新请求重算 → 新旧结果差异。接受 annotation 是操作性复核，不新增整项研究的人为门禁。多客户端修改同一父版本返回冲突，保留两个候选版本。旧结果和关联主张标记待复核。

克隆/细菌最小粘连处理采用显式手工切断/掩膜编辑，不默认 watershed。后续自动拆分作为另一个固定算法版本和参数，必须独立验证。点计数修订与像素掩膜修订不同：手工新增点没有可推导面积，计数/面积分别报告；不得把点数修改伪造成分割面积改变。

### B. 样本、时间、孔位与 CFU 元数据契约

- 划痕：`sampleId, biologicalReplicate, fieldId, timeValue, timeUnit, baselineItemId`。同一 field 具有唯一时间点；缺点列入 missing，禁止插值冒充观察。基线从成功且接受的原生面积结果引用，不能复制任意数字。相同源坐标/尺度/图像注册记录后才比较；像素尺寸不同时使用可核验物理面积或阻断。视野/ROI 不可对应时不算闭合率。允许负闭合率并打扩张标记，不截为零。
- 克隆：`plateId + wellId` 唯一对应图像/ROI，`sampleId/group/biologicalReplicate/technicalReplicate` 分开；`seededCells` 可空。仅有计数仍可完成；提供有效接种量才计算克隆形成比例。存活分数还需对照 plating efficiency，不能把 count/seededCells 自动称为生存分数。
- CFU：计数和浓度分开，`reciprocalDilution`、`platedVolumeMl` 可空；未知时 CFU=null 并给缺失原因，零不能代替未知。明确 dilution 是倒数 1000 而非溶液分数 0.001，UI 显示单位。不同稀释度合并须另有预设估计方法，首版只逐平板报告。排除反光也意味着不可观察区域：不默认按面积外推总体 CFU。
- 成管：`sample/field/replicate/time` 记录，保留所有插件字段。长度用实际边长与标定，图环不是生物学独立样本。
- WB：复用现有 lane→biologicalReplicate；技术泳道不得被批处理聚合成增加 n。汇总保留每膜/曝光和 QC 状态。

### C. 最小持久批处理

统一批次 manifest 不包含执行代码。每项唯一 itemId，引用资产/修订/方法参数、样本契约和依赖（例如 scratch baseline）。批次 manifest 冻结版本及哈希；每项调用既有 Runner、生成独立 Run/Artifact。大文本 JSON 不能成为多个 Agent 任意写入的队列。

只新增一个持久 Batch/Item 对象和有序调度器，或复用现有 ResearchTask 持久队列但不能强制普通文件操作建立医学研究。单本地 Fiji 执行槽，应跨 WB 和另外四类共享；当前 `fiji-image-runner` 进程内 active 仅覆盖四类，不足以宣称所有 Host/WB 跨连接并发限制。

恢复首先核对 Run、完成 Manifest、任务所有权和哈希；已完成项不重跑。失联项到期明确失败，用户显式重试形成 attempt；不根据历史 PID 推断存活或杀进程。取消当前 owned child 和未启动项，保留成功项；默认独立项继续，基线失败只阻断依赖项。输出每个声明 item，包括失败/缺失/取消，禁止仅导出成功行。

## 3. 已生成的独立参考样例

生成器：`tools/science/fiji-workflow-reference-fixtures.py`，仅 Python 标准库，不导入产品算法。输出 PGM 原图、二值排除/修订掩膜、manifest 和校验报告。通过几何构造提供独立预期值，不用待验收实现反算“正确答案”。

| 样例 | 独立预期 |
|---|---|
| S1 同一视野 0/24/48h | 面积 48/24/0，闭合率 0/50/100%；缺 24h 时只报告缺失；扩大到 60 时 −25% |
| A1 克隆原图 | 阈值前景 51 像素；面积筛选后 5 个颗粒，另 1 个 debris；排除反光和边缘后 3 个、37 像素 |
| A1 人工拆分接受掩膜 | 4 个独立 3×3 方块，36 像素；接种 100 得 4%，B1 缺接种量仍报告 count=1、比例=null |
| 同图细菌平板 | 修订后 4 个，倒数稀释 1000、体积 0.1mL 得 40000 CFU/mL；缺体积则 count=4、CFU=null |
| 成管闭环与断环 | 原生图环 1→0；长度需另跑同版本原生插件参考，不用矩形周长或骨架像素硬套 |
| WB 四泳道 | 背景扣除 200/400/490/200，loading 100/100/100/0，normalized 2/4/4.9/null；第3条饱和，第4条 loading 不成立 |

该样例包只为合成软件验收，不具有生物学独立重复、统计功效或真实实验有效性的含义。人工拆分几何预期不代表所有真实粘连可用相同处理。

## 6. 本轮实际实现与冻结证据

已实现：

- CFU 元数据可省略/null；继续计数、CFU=null 和缺失标记。倒数稀释必须 ≥1，拒绝 0.001 混入倒数；零体积拒绝。克隆新增接种量及 count/seededCells，未知保留 null，不称为对照校正存活率。
- `image.review` 引用同资产/源哈希的最新 accepted AnnotationRevision；区域必须为第 0 页矩形/多边形。缺 foregroundRoiIds 使用自动阈值，显式数组用区域并集替代前景（空数组为空），最后应用 excludedRoiIds。坐标由原图转换到 ROI-local。保留自动/接受/排除掩膜、接受修订JSON及原有原生结果。用户源图不变，历史结果不覆盖。
- 原生 Runner 实际调用 ImageJ ROI 栅格化和 ParticleAnalyzer/Skeletonize3D/AnalyzeSkeleton；不以 TypeScript 近似结果冒充。对接受修订使用稳定哈希进入执行指纹；过期或冲突修订拒绝。
- 划痕 `timeline` 冻结样本/视野、小时、预期时间点与来源明确的像素间距。0h初始面积来自实际掩膜；后续引用真实基线 Run/结果 checksum，忽略手填 initialArea。错样本/视野、ROI/尺度或时间计划改变拒绝；同基线同时间点原子幂等，变参冲突；报告 observed/missing 时间，不插值。
- 读取结果实时校验源/标注修订；基线源或标注过期向后续状态传播 needs_recheck。已有 Store 标注修订机制负责直接关联产物/证据/主张失效；没有另改 Store。跨基线的间接主张持久化失效仍需研究编排统一处理，不能仅凭运行成功认可主张。
- 实验 UI 提供ROI/阈值/标识、接受修订、排除/前景区域、CFU元数据、接种量、时间序列/真实基线/标定字段；提供历史任务及产物恢复。参数JSON保留高级编辑入口，常见新增操作无需手写字段。会话/资产切换防止迟到响应写入旧修订选项。

原生独立参考：`.build/fiji-review-native/2026-09-22T06-21-47.529Z/report.json`。实际 ImageJ/插件验证：原始5颗粒→排除后3颗粒/37px→接受人工修订后4颗粒/36px；接种100对应0.04；缺量CFU=null，完整量CFU=40000；划痕48/24/0面积对应0/50/100%；相同时间点幂等/参数冲突；wrong sample/spacing拒绝；成管闭/断环1→0；修改基线源后后续needs_recheck。
