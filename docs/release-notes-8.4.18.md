# ZeroWall Science 8.4.18

- 修复内置 RMCP 连接的兼容路由：正式连接名为 `rmcp`，旧名 `zerowall-rmcp` 会自动迁移并在调用时规范化。
- 当实际调用 R、FAERS、GEO、NHANES、文件传输或其他 RMCP 能力时，Host 会按需刷新 RMCP 的实时工具列表；如果内置记录缺失或被停用，会自动修复并启用。普通用户 MCP 仍保留原有启停状态。
- 区分 Host 本地的连接状态错误与远端 RMCP 错误，保留可操作的远端诊断，避免把 `disabled or unknown` 误报为远端返回。
- `research_task_id` 改为可选本地绑定字段。普通远程工作流不再被占位字符串阻塞；只有真实 UUID 才执行本地任务存在性、工作区和 Run 归属校验。
- 远程工作流和文件传输自动创建并复用当前对话的服务端项目绑定，不再要求用户填写 R Platform `project_id`。
- MCP 能力搜索按服务器名和工具能力模糊匹配，仅刷新命中的服务器并加载匹配的实时工具，减少待命连接和工具上下文。
- 继续保留模型、推理强度、账户、项目、用户自定义 Skill/MCP、禁用状态和固定版本选择。
