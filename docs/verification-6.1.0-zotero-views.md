# 6.1.0 Zotero 与会话标签修复验收

验证日期：2026-09-17。使用用户提供的 `session.v3.jsonl`，仅在临时用户目录中复制回放；原日志和正式用户数据未修改。

## 根因与修复

- 日志的 seq 47/48、75/78 是 `tool_dispatch` 根调用，没有嵌套的 Zotero 调用事件。转发结果只保留协议和工具名，丢失 Zotero 列表所需的结构化展示元数据。原有缓存刷新修复不足以解决此问题。
- 工具转发现在通过原有执行管线完成后保留 `meta.targetMeta`。Zotero 客户端解析转发调用的真实工具名、参数和元数据。对于旧记录，仅从检索工具的严格格式结果行恢复列表，不采集助手正文中的参考文献，也不伪造附件引用。
- SSH 曾通过 DOM 插入外观类似标签的按钮，点击只打开侧栏，主区域仍是原对话。现在注册正式 `conversation.view`，侧栏打开按钮放入独立工具区域。
- 主框架的常驻输入框与所选视图无关，因而每个标签都有输入框。打包适配根据真实主标签隐藏非对话页的输入框，保留编辑器和草稿，并限制选择器作用范围。
- 保留 issue #4 的附件批注过滤修复：附件子项请求显式传递 `itemType=annotation`。
