# ZeroWall Science 7.0.6 发布说明

7.0.6 修复科研工作台的自动跳转、文件切换和查看器状态问题，并保持 7.0.5 的九卡片入口与只读查看方式。

## 科研工作台

- 工作台每次进入时显示九张工具卡片，不恢复旧工具页；历史工作台事件仅用于审计，不驱动页面导航、资产选择或自动分析。
- 脑图谱仅在点击“打开脑图谱”时启动，在点击“读取切片”时读取切面；不会在进入页面时自动执行 BrainGlobe 分析，也不将托管图谱误报为用户当前选中的资产。
- 九个查看器使用一致的居中空状态、资产栏和查看区。文件选择按查看器限制后缀；切换文件后旧画面立即清除，迟到的旧请求不能覆盖新资产。
- 修复细胞查看器打开新 H5AD 后旧散点图仍显示的问题；现代 AnnData 使用的 nullable 字符串索引可直接读取，无须改写原始文件。细胞散点图扩展至可用查看区域。
- ImageJ、HE、流式、序列、Sanger、分子及科研画布的刷新与失败状态按实际结果显示；分子三维画布在文件切换期间保持稳定挂载。高级分析、导出和实验动作仍通过相应技能调用。

## 引擎与兼容

- BrainGlobe 托管图谱探测兼容已有图谱目录；引擎中心据实际配置与探测结果显示状态。
- 远程 R 使用已配置的 RMCP 端点和环境变量连接参数；配置状态不再把尚未探测误写成不可用。
- 保留 7.0.4 的稳定 Python 目录、依赖检测和镜像重试，以及 7.0.5 的模型协议、模型同步与科研引擎设置修复。

## 已知限制

- 专用查看器只显示已有数据或图谱；分析、分割与科学复核需通过技能和 Host 运行结果完成。
- 原生引擎依赖本机对应安装及模型资源。启动进程后若无法确认窗口状态，不报告 GUI 已成功打开。
