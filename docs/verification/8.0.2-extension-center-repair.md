# 8.0.2 扩展中心修复与本地安装包验收

日期：2026-10-02。分支：`dsh-allupdate`。本报告记录本轮修复后的最终候选包；不代表线上发布或用户实际安装验收。

## 问题与修复

用户截图中的 `Catalog download failed`、`unknown` 版本以及不完整的插件清单，来自三个不同的缺陷：

1. 独立更新目录尚未公开，远端返回 404。旧界面将其归为下载失败，并同时显示“已完成检查”。现在区分本地、未发布、不可用和已检查状态，404 显示“独立更新目录尚未发布。本地资源可正常使用，发布后可在这里检查更新”。网络与签名错误仍保留诊断信息，桌面桥接读取失败不会伪装成检查成功。
2. 7.5.0 的自有功能由桌面 overlay 加载，插件化后改为 profile 管理。早期迁移仅补入扩展中心，遗漏桌面桥接、Skills、MCP、环境等服务。迁移版本现为 `pluginArchitecture: 4`，覆盖没有 marker 的旧 profile，以及 architecture 2 的扩展中心-only profile；现代 profile 中用户已移除的插件不会被重新加入。
3. 旧清单仅列出 profile 声明，遗漏核心 overlay、侧边栏等实际包，部分内置包未读取真实版本。新清单合并实际资源来源，隔离默认环境显示 36 项插件资源（25 个由 profile 管理的插件）；DSH 核心显示 `0.2.0-rc.2`，自有和第三方包显示实际独立版本。

本次同时完成以下修复：

- 扩展中心仍只在设置中注册，不新增 Better Sidebar 页面。
- 自有插件显示中文名称、完整包 ID、中文来源与状态；长 ID 换行，操作按钮分组，800px 窗口没有横向溢出。
- 核心 DSH 包不提供停用或卸载；内置与用户安装插件按原有边界管理。
- 本地清单先加载，catalog 网络检查移出 profile 事务锁并设 10 秒超时；`check` 调用正确传递选项。
- 保留依赖固定版本、第三方选择、自定义 patch 及停用/移除状态；去除已有 profile 与桌面 overlay 重复的核心声明。
- 修复 Better Sidebar `cordis.patch.yml` 未进入安装包，以及当前 DSH pin 的 HMR 禁用补丁名称不匹配问题。
- 显式隔离用户目录不复制真实 Windows legacy 数据，验收过程不修改用户实际配置。
- `zws plugin list` 补全插件来源；提供 `zws help`、`--help` 与子命令帮助。`zws skill update <目录>` 正确调用本地 Host 热刷新。
- Skills 导入使用目录，MCP 操作使用 connection ID；补充相关启停操作。
