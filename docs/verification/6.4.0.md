# ZeroWall Science 6.4.0 验证记录

本次先完成 Windows x64 安装包的本地构建验证，随后按用户指令发布七牛和 GitHub；不替换本机真实用户安装。客户截图来自其他电脑，不能据此确认那台电脑的缓存内容、安装范围或旧进程路径。

## 改动

- 移除 OpenCode 免费模型依赖、补丁、注册、默认配置、运行资源和对应远程测试。历史默认选择迁移到现有默认服务，不注册免费模型适配器；历史对话不删除。
- 更新安装前验证目标版本大于当前版本、文件名、SHA-512 和 EXE ProductVersion。失败时不停止 Host，不退出应用；重复安装点击复用同一请求，普通退出不自动安装。
- NsisUpdater 明确指定当前 EXE 所在目录。安装器恢复原注册范围和目录，支持所有用户安装提权；同名其他目录程序不会被结束。
- 安装器从固定的 electron-builder 26.15.3 模板生成覆盖安装段，不执行旧 Electron 卸载器。只清理随程序交付的专属资源目录，再覆盖新版；保留安装目录的其他文件。仍使用上游卸载器生成机制。
- MinerU 默认开启 OCR，持久化任务批次，支持恢复查询、内容清单 v1/v2，以及 Markdown、图片、表格、页码和 bbox 交接。四个科研技能使用托管 Python、中文路径解码和检查点续跑。

## 边界

- 当前测试账户没有管理员权限，所有用户安装的实际 UAC 同意流程未执行；不得将当前用户安装回归表述为 HKLM 实机验证通过。
- 无法直接读取客户机器的旧下载缓存，不能宣称已复现客户“显示新版却启动 6.2.0”的唯一根因。增加的版本/哈希检查和固定原目录行为分别防止错误安装包与错误安装位置。
- 6.4.0 安装后才具有新增的应用内更新校验。旧版客户端不会因发布而自动获得该校验代码，需先升级到本版本。
- 检测 findings 是可追溯的筛查线索，需要人工复核；未启用的可选检测仍在报告中列明。
- DSH 保持 `0.1.5-rc.2`，精确 commit 为 `357e3ff6ca3a4e43e86c2549626c6bde0be5844b`；保留 `.upstream/` 和用户现有数据。

```powershell
node desktop/scripts/verify-installer-upgrade-640.mjs
```
