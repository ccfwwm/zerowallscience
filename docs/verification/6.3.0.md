Date: 2026-09-18. Platform: Windows x64. The artifact was rebuilt after the final desktop and installer changes.

## Delivered changes

- The installer opens as a modern native Win32/Direct2D screen. It installs for the current user by default; the installation directory and desktop shortcut controls are behind collapsed advanced options.
- Installation phases report preparing, extracting, finalizing and completion through a 14 px progress track with an independent animated light sweep. Reduced-motion mode keeps a slower progress animation.
- Windows uses a frameless integrated title area with red, yellow and green controls for tray hiding, minimize and maximize/restore. The control IPC accepts only the trusted top-level document.
- The installer and startup splash emphasize the complete research workflow, complete literature workflow, intelligent medicine and ready-to-use experience, with dynamic version text and a wide animated track.
- A precise `[data-sidebar-header]` selector replaces the broad window-chrome selector that accidentally constrained the whole sidebar to 92 px. Session history fills the available height and Settings stays at the bottom.
- Archived sessions have a persistent sidebar entry with title/workspace search, content viewing and explicit restoration to the original workspace. Opening an already archived session no longer immediately clears its content.
