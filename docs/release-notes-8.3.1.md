# ZeroWall Science 8.3.1

- 修复插件 profile 切换后 pnpm 仍引用候选目录，造成官方插件安装、升级和卸载失败的问题；本地旧记录自动修正，不清空用户插件和设置。
- 统一桌面与命令行的安装工具链；store 不兼容时保留原依赖树和声明文件，失败恢复，成功后重试一次。
- 桌面兼容桥读取真实的活动 profile；扩展操作失败后刷新实际安装、停用和任务状态。
- 升级弹窗正文独立滚动，标题和底部操作按钮保持可见，适配长更新说明及较小窗口。
- Python 依赖按签名清单逐包安装；不再在安装过程中运行导入探测或全环境 pip check，避免资源包和暂缺传递依赖导致已安装文件回滚。实际下载、安装失败仍保留重试记录；环境诊断可单独执行。
- 云平台 HTTP 400 upstream_error 按上游临时故障处理；断流和临时网络故障在当前步骤最多重试 5 次，保留模型和推理参数，使用 DSH 原有可取消退避与重试状态。
- PPTX Skill 明确新页面必须先用 gpt-image-generator 生成整页不可编辑的图片原型，查看后再还原为可编辑页面；还原及润色阶段继续支持独立插图、图标和背景的生图/改图，不混用媒体生成配置。
- 新桌面打包集成共享插件目录中的全部最新兼容包；复用未变化归档，拒绝旧 stage、清单降级和缺包。

本次变化的插件为 Base 0.1.18、Desktop Compat 0.1.5、Extension Center 0.1.13、Python 0.1.19、AI Cloud 0.1.19、Univer Office 0.3.7-zws.6；zerowall-presentation/univer-slide Skill 更新为 0.1.6。`dsh-orb` 仅作为第三方插件安装/卸载测试，不集成到默认组合、离线闭包或资源 catalog。
