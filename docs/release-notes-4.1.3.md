# ZeroWall Science 4.1.3

## 修复

- MCP stdio 连接启动前会在 Host 边界把工作目录、本地命令路径和路径型参数统一解析为绝对路径。裸命令名与 `@scope/package` 包名保持不变，不再受开发目录或打包后 Electron 启动目录变化影响。
- 对话文件选择器不再按后缀筛选。任意文件均可先进入本地附件管线；PDF、Office、表格和文本等已知格式继续结构化解析，未知或解析失败的格式按 SHA-256 原样保存并交给 Agent 判别。
- 新增 `materialize_uploaded_file` 工具。Agent 可将当前会话明确引用的原始附件安全落到会话工作区，再调用合适的 Skills、命令或文件工具处理；文件仍受 50 MiB 单文件上限、会话引用检查和工作区边界约束。
- 不属于原生图片输入集合的图片 MIME（例如 SVG）会进入通用文件管线，不再先被图片格式校验拒绝。

## 安全边界

附件内容仍被视为不可信数据。原始文件不会自动执行；只有当前会话已经引用的附件才能由 Agent 物化到 `.zerowall/uploads/<sha256>/`，已有目标必须是内容哈希一致的普通文件，符号链接和冲突内容会被拒绝。
