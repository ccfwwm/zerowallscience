# ZeroWall Science 6.0.0

本次更新升级至 DSH 0.1.5-rc.2，修复附件、会话、插件设置与 MCP 生命周期兼容问题，包含桌面插件和随包 Skills。

- 环境状态按文件版本缓存，减少反复解析大型 Python 环境清单。
- 环境诊断日志只写入状态与审计摘要，不再重复写入完整技能清单。
- 将远程 `r_files` 保留为内部调用目标，模型仅看到统一入口，减少重复工具定义；本地文件下载能力保留。
- 已启用的 MCP 在 Host 启动后异步建立连接；并发请求复用同一次连接，30 分钟状态轮询不会主动重连。
- MCP 工具调用默认超时 300 秒、重试 2 次；连接和状态检测超时 120 秒，状态及后台检查间隔 30 分钟，状态轮询不主动重连。
- 内置 MCP 设置支持保存与修复；中英文切换包含环境配置字段。
- 设置面板使用不透明背景，避免窄窗口下聊天内容透出干扰阅读。
- 官方 dsh-file-review 0.8.1 替换 dsh-file-review-tab，保留文件差异审查。
- 修复混合附件输入、已提交文件重试、附件预览和复制、解析状态，以及历史轮次跳转和滚动位置保持。
- 项目归档支持旧版会话迁移与新版会话导入导出，校验摘要与事件内容，拒绝覆盖已有会话。
- 为 Harness 无换行输出增加缓存上限。
- 修复新版 DSH 命令入口的桌面启动适配，并排除退役微信插件残留的重复运行时依赖。
- 桌面模块解析改用同步解析钩子，减少启动时逐模块跨线程解析开销。
- 移除能力管理模块及其工具筛选、目录、转发和设置界面；MCP 与 Skills 使用原生入口。修复 Skills 客户端服务获取。
- 定位到原能力模块对 `r_files` 的会话别名遮蔽会触发无限递归，导致上传无结果、Host 失去响应并最终 OOM。本版不再加载该模块，保留递归回归用例防止再次引入。
- 移除 AI 自动审查入口；官方文件差异审查保留。
- 左下角快捷入口默认收起，设置始终可见；展开状态独立保存，并增加微信 WebChat 状态和配置跳转。
- 兼容旧会话的文件审查标记、能力选择事件和已解析附件元数据。读取旧记录时不覆盖原始文件。
- 原生 PDF 上传后自动解析：已配置 MinerU 时优先调用 MinerU，未配置或解析服务不可用时回退本地解析；聊天恢复附件卡片，解析正文保留给模型。

本次回归验证包括完整 DSH Host/Client 构建、MCP 按需连接与保存测试、附件与会话迁移测试、打包程序界面验证。246 份现有旧会话通过只读格式恢复检查；截图中的历史会话通过打包 Host 读取；未配置 MinerU 的 PDF 在打包程序中成功本地解析。MinerU 分支通过模拟服务测试，本次未调用真实 MinerU 在线服务。

升级不会删除现有会话、附件、项目、凭据或 zerowall-python 环境。上述改动降低已识别的内存与上下文开销；长期运行稳定性仍需持续观察，不等同于已排除所有 OOM 原因。

适用平台：Windows x64。安装前请保存任务并退出旧版软件。
