# ZeroWall Science 4.3.8

## 修复内容

- PPT 工作台的“打开所在文件夹”现在会调用 Windows 文件资源管理器并定位当前 PPTX，不再跳转到应用内工作区页面。
- 提升“重新生成当前页”按钮的前景、背景和边框对比度，并保留清晰的悬停、聚焦、禁用和加载状态。
- 修复完全权限会话重复传入 `workspace-write` 或 `danger-full-access` 时的错误。当前权限已经覆盖请求权限时，FS、PowerShell 和 Bash 工具会忽略冗余升级参数；真正拓宽权限仍需非空理由和用户审批。
- 移除 PPT 的“质量：待确认”和人工确认提示。PPTX 组装完成后直接进入完成状态，用户可通过逐页缩略图自行检查结果。

## 兼容性

- 历史演示文稿中的质量字段和旧 `quality` 阶段仍可读取，避免影响已有本地数据。
- 本版本仅生成新的 4.3.8 本地安装包，不覆盖既有 4.3.7 及更早版本文件。
