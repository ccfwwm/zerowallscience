# ZeroWall Science 7.0.1

## 科研工具工作区

- 新增顶部工具标签工作区，当前工具使用助手栏与中央专业视图联动，不增加应用级左侧导航。
- 对话和 Agent 可以打开工具、聚焦资产、跟踪运行任务、接收进度与产物事件。
- 事件按 session 持久化序列记录，支持去重、断线游标恢复和幂等请求。

## 科研引擎中心

- 支持为 Fiji/ImageJ、napari、HE、BrainGlobe 和远程 R 配置路径、环境、版本与诊断。
- Fiji 默认探测 `C:\\softworks\\Fiji`，支持用户覆盖、真实 bundled Java 探测和可操作错误信息。
- 未配置或无效的引擎保持对应状态，不伪造为可用。

## 验证

- 研究插件全量测试通过：58 个测试文件、311 个测试通过、2 个跳过。
- Windows x64 packaged runtime、中文设置切换和版本显示验证通过。
