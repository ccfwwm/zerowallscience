# ZeroWall Science 8.1.1

本版本修复 8.1.0 覆盖安装后无法启动，以及共享 Python 和 Bio MCP 的运行时问题。

- 覆盖升级先替换安装器拥有的离线物理运行时，清除旧 hash 资源和已改名插件，继续严格核验签名、文件集合和 SHA-256；保留安装目录旁的用户文件和用户配置。
- Python 与 MCP 统一使用 Host 记录的唯一共享运行时投影，保留签名 archive manifest，不重复拼接 `Python` 目录。
- Python bootstrap 缺少 Bio MCP 核心依赖时可独立激活；核心层安装后的候选服务仍须通过健康检查。缺少依赖时显示明确的待安装提示。
- MCP 候选启动错误保留并脱敏 stderr，避免只有 `closed`。健康检查完成后关闭 stdin，让 stdio 服务正常退出。
- Bio 请求取消后禁止重复发送响应，保留其他协议断言和错误。
- Win32 目录选择器使用 Koffi 的复制式 UTF-16 解码，释放 COM 分配内存并保持 IPC 到最终结果。
- 延续启动和每日只读更新检测、更新弹窗、左下角提示及扩展中心界面；插件与 Skills 仍独立更新。

仅变更的独立插件递增版本：Python `0.1.3`，MCP `0.2.10`。DSH 子模块保持 `86b6740d0e671cee0b3fd0168de484c0efbf46ea`。构建使用组件指纹和内容校验缓存，复用未变的编译产物及资源归档。

安装验收、构建哈希、签名资源目录和公网发布收据见开发指南第 17 节。更新后请完全退出旧进程，再运行安装器覆盖安装。
