# ZeroWall Science 8.4.1

- 插件安装使用独立 pnpm 解析目录，保留现有插件及其完整依赖实例，避免旧安装元数据误删插件。
- 修复嵌套依赖物理化时产生自身目录联接的问题；扩展中心可识别循环和断链，并从可信离线供给恢复候选 profile。
- 安装复制辅助运行环境与应用载荷分离，保留原始安装错误、回滚和清理诊断，支持重试和中断恢复。
- Windows 应用保留启动用户身份；安装器仅在目标目录需要写入授权时请求 UAC，用户注册、PATH 和启动回到原用户进程。
- 统一浏览和输入的安装路径，升级改目录保留原有固定 Python 路径及用户文件。
- 受保护 Python 目录的签名维护使用独立授权 worker；自动任务遇到权限限制时等待手动授权。
- 左下角使用齿轮“设置”按钮，直接打开设置。

本版本仅制作本地候选安装包，不发布至七牛或 GitHub。DSH 子模块保持原版本。
