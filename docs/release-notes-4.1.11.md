# ZeroWall Science 4.1.11

## 修复与改进

- 修复提问选项不弹出：纠正图片消息容量与 HTTP 传输上限冲突，事件通道可以稳定连接，结构化提问会显示单选、多选和自定义输入卡片。
- 增加打包发布门禁：真实验证 `events.mux` 和 `events.host` 的首连、第二客户端连接及断线重连。
- 增加无密钥提问交互验收：Windows 安装包必须实际显示单选和多选控件，并将答案回传后继续会话。
- 保留单张图片 50 MiB 上限，将单条消息的图片总量调整为 100 MiB，避免传输桥接器缓存超大请求导致内存风险。
- 保留 4.1.10 的完全权限、MCP 自动刷新和内置 Python 环境修复。

本版本仍只提供 Windows x64 安装包。MCP 环境继续执行签名、压缩包大小、SHA-256 和 Python/MCP 健康检查。
