# ZeroWall Science 4.3.5

- Fixed Stable client plugin loading by keeping the `slots` service in generated client injection manifests.
- Fixed `dsh-better-sidebar` startup under the strict DSH Loader by declaring the `conversation` service used by its client bundle, with a packaged-runtime regression audit.
- Enabled the 科研图片查重 workbench and 演示文稿 workbench as discoverable right-sidebar tabs.

- Rebuilt the Windows Stable package with the image duplicate-check and presentation plugin bundles included.
- The presentation workbench now keeps both creation paths: select an existing research project and enter a title manually, or choose the current workspace for automatic project association.
- Added the `zerowall-ppt` default Skill, which routes PPT requests to the `create_presentation` plugin tool; all legacy PPT Skills are removed from the product.
- Fixed one-page PPT output: a title-only request now produces a six-slide research deck, while an explicit outline produces one slide per section.
- Linked manual PPT creation to a new conversation in the selected project workspace and automatically opens the matching right-side workbench for conversation tool calls.
- Reuses the same presentation record and overwrites the same PPTX/PDF artifacts for same-title updates; `update_presentation` edits the open deck in place instead of creating duplicate files.
- Added visible generation stage and percentage status plus a real generation regression test covering multi-slide output and in-place regeneration.
- Completed the image duplicate-check result flow: suspicious pairs are selectable, source images can be opened for review, and HTML/Markdown/JSON reports can be previewed, downloaded, and opened from the workbench.
- Refined the presentation workbench with localized stage labels, a persistent progress bar, explicit generation controls, page counts, quality guidance, and clearly named PPTX/PDF artifact actions.
- Unified PPT creation under the ZeroWall presentation pipeline: each slide is generated as a full 16:9 visual with the configured or automatically discovered exact `gpt-image-2` model, then assembled into the existing presentation's PPTX/PDF artifacts.
- PPT generation now stops with an actionable environment-configuration message when no usable `gpt-image-2` model exists; it does not silently fall back to the former text template.
- Removed the three legacy PPT Skill entry points from product resources and Stable packaging so PPT requests consistently use `zerowall-ppt`, `create_presentation`, and `update_presentation`.
- Fixed the Windows native folder-picker worker's packaged module resolution and diagnostics. Scientific image duplicate checking now falls back to the in-app directory browser when the native picker cannot complete, while preserving session-scoped directory grants.
- Scientific image duplicate checking now uses the desktop's secure Electron directory dialog directly, avoiding the unstable native DSH worker for user-selected folders while retaining scoped directory grants.
- Fixed packaged GIF scanning by preserving npm runtime JavaScript published under `src` directories. The Stable runtime now includes the complete Jimp `gifwrap`, `omggif`, and `any-base` dependency chain instead of treating executable package code as development source.
