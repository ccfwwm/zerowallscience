# ZeroWall Science 5.20.0

## 本次更新

- 修复工具上下文爆满问题：MCP/RMCP 工具默认改为按需加载，不再把完整工具目录常驻注入每次模型请求。
- 将常驻工具面收缩为能力搜索/执行、结构化输出、基础文件与终端工具，显著降低首次请求上下文。
- 修复 capability policy 中 server 级按需规则与 resident 通配规则的优先级冲突。
- 对模型请求工具面按最终名称去重，避免多个适配器重复注册同一工具 schema。
- 新增 MCP 按需暴露、原生工具保留和策略冲突回归测试。
- 完整打包内置插件与桌面运行时，保持现有 Literature、工作区文件桥接和研究能力兼容。

## 兼容性

- 不删除任何工具能力；MCP 工具通过 `capability_search` 与 `capability_execute` 按需调用。
- 保留现有会话、项目目录、附件和凭据，不迁移或清理用户数据。
- Windows x64 稳定版安装包版本为 5.20.0。
