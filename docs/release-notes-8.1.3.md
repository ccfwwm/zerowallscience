# ZeroWall Science 8.1.3

Python 统一使用实际安装目录下的 `Python/python.exe`，或用户明确选择的固定根目录。旧 LocalAppData 环境和 slots 不迁移、不删除，也不再用于正常执行。本地包按规范化包名是否存在判断，默认补缺不升级或降级已安装版本。

Python 插件独立携带验签 worker、真实 pip 检测、持久任务、安装和诊断页面。首次显式安装先初始化 CPython 3.12.10 / bootstrap 1.5.2，再安装所需依赖。依赖清单为核心 43 包、科研 529 包的 r18；源码构建使用临时解释器，支持五个签名七牛 fallback wheel，cobra 使用官方 wheel。检测、预览和启动检查保持只读。

运行时更新采用同目录文件事务和租约，回滚恢复固定路径。Python、pip、依赖和 MCP 分别报告状态。Python 工具输出摘要并保留完整分页结果。卸载按安装器文件归属删除应用文件，保留 Python 和用户文件。

插件批量下载和准备后统一激活，正常流程只重启一次 Host；准备失败保留旧 profile，健康检查失败整批回滚。AI 云平台提供按分组同步结果、可搜索模型列表和标准托管供应商卡片，保留用户模型与协议设置。费用和价格入口位于账户卡片。

BioGenie 独立为 0.1.3 插件，上游固定 0.6.48，包含操作目录、Python 桥接、源码、资源、许可证和来源记录。能力发现不要求环境，执行共用固定 Python，并保留 SBOL、Bio Tools 默认检索路由、上传确认与 Research Store 记录。Python 插件为 0.1.7，账户和 AI 云平台均为 0.1.6，科研组合声明为 0.1.13；版本递增避免覆盖已暂存的不可变资源。

NSIS 使用安装器文件清单和原始文件接口复制完整载荷，修复中文、空格和长安装目录下的静默漏文件。首次 Python 下载失败保留原始错误与断点，避免后续检测将下载错误覆盖成“解释器不存在”。

升级直接覆盖新版离线运行时，不依赖旧版收据、版本号或旧文件哈希。新版签名文件集以外的旧残留逐文件直接删除，不创建备份，兼容旧版展开目录及冗余归档，避免多余文件阻断启动；新版签名、大小和 SHA-256 在复制前严格核验。Python 和离线运行时目录以外的用户文件保留。

Python 插件和 `zerowall-python-packages@0.1.4` 默认使用中科大 `https://mirrors.ustc.edu.cn/pypi/simple`，保留用户明确保存的镜像选择；“恢复默认”选择中科大。HTTPS 验证、完整下载校验、断点续传及按包重试保留。

本文描述本版本变更范围；构建、真实安装验收、已知限制与七牛公开校验以 `artifacts/verification/8.1.3/` 和发布收据为准。
