# 7.0.0 科研画布图像与不确定性

本轮实现以现有画布为基础，源代码尚待下一次统一打包；14:00 的安装包不包含本轮新增项。

- 图像面板从当前项目已登记的资产或分析产物选择 PNG、JPEG、WebP；Host 核验项目路径、格式和源哈希，按原始纵横比内嵌 PNG。拒绝动画/多页和带旋转 EXIF 的图像，避免标定轴被隐式改变。
- 比例尺必须由用户提供长度、每原始像素的物理单位、单位名称和标定来源；显示长度根据源像素与面板显示比例换算。超过原图宽度 80% 的标尺拒绝渲染。它不从照片内容猜测显微标定。
- 数据点可传入 `yLow`/`yHigh`；必须同时提供系列 `intervalLabel`，如 SD、SE、95% CI。上下界必须有限且包含估计值，自动坐标范围覆盖区间。图例和 SVG title 保留区间含义，不计算统计量。
- 每文件输入上限 32 MiB/1600 万像素，规范化 PNG 上限 24 MiB，整张画布内嵌图像上限 48 MiB。原始大图须先由查看器导出合适切片。
- 原子导出仍为 SVG、PNG、图像版 PDF 和可编辑 JSON；JSON 保留源版本、原始文件哈希、图像像素尺寸及比例尺参数。源产物 `needsReview` 继续传播到图表产物。

实际 React→Host→Chromium 验收：`.build/canvas-viewer-smoke/2026-09-22T06-12-00.162Z/report.json`。三个面板包含数据曲线、显式非对称 95% CI、200×100 合成图像与 25 µm 标尺；四个导出文件逐个 SHA-256 核对，草稿刷新恢复通过。此基准仅验证几何/交互，不提供医学或出版评审结论。

并行复核后补充：预览/导出写回源 SHA-256 与原图尺寸绑定，旧工程拒绝更换图像后沿用旧标定；用户需显式重新绑定并重新标定。登记产物在 Store 事务内核验所有来源版本，阻止导出期间源修订漏失效。上游 scientificReview=pending 继续传播；导出工程不超过导入 32 MiB 上限。

仍需完善自由拖拽布局、图像坐标标注、更多统计图形和出版人工复核。
