# ZeroWall Science 5.19.0

## 本次更新

- 更新内置 ZeroWall Literature 技能，增强引文作者画像检索、作者身份线索回灌、主页抓取与离线证据复用。
- 优化作者职位、机构、国家、研究方向、荣誉与学术任职提取，减少履历旧职位、他人信息和页面导航文本造成的误配。
- 调整作者检索策略：每位作者仅执行一次定向搜索，重点作者使用 Tavily，其余作者使用 DeepSeek 官方搜索，降低重复请求与等待时间。
- 强化引文作者 OpenAlex 标识、规范姓名、机构、国家和研究主题的消歧线索，支持重新生成作者请求并避免旧证据覆盖新结果。
- 修复 MCP 工作区下载调用的参数归一化与文件桥接路由，提升通过能力菜单下载工作区文件时的兼容性。

## 兼容性

- 保持 cited-by 引文分析边界，不扩展目标论文参考文献。
- 目标论文继续支持 MinerU 解析；引文 PDF 与作者、期刊分析保持独立可恢复。
- 兼容现有 Literature 任务目录和历史证据账本。
