# ZeroWall Science 5.13.0

本版本修复托管科研 Python 环境更新超时和无进度反馈，并升级文献引用分析流程。

## 托管科研环境更新

- 环境更新改为后台异步执行，点击更新后界面保持可用。
- Python 环境页实时展示检查、下载、校验和安装阶段，并显示下载百分比。
- 启动后及每小时自动检查并安装新的签名环境版本或内容修订。
- 健康检查只导入 `mcp`、`numpy`、`pandas` 等最多三个轻量核心模块，不再因完整科研包冷启动而超时。
- 更新期间的手动检查不会覆盖正在进行的下载和安装状态。

## 文献引用分析

- 目标论文先下载并通过 MinerU 解析，再展开 cited-by 引用网络。
- 被引论文只下载保存，不做无必要的全文解析。
- 加强引用关系、全部作者、机构、国家、期刊和影响力分析。
- 输出展示型离线 HTML、PDF 和带工作表说明的 Excel，保留可审计的下载与数据来源。

## 发布信息

- Windows x64 Stable 安装包版本为 5.13.0。
- 托管 MCP 环境继续独立使用线上 `1.2.0 / 修订 1` 签名清单。
