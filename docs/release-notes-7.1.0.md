# ZeroWall Science 7.1.0 发布说明

## 科研完整性筛查

- 论文图片增加整图、跨图、跨文件及局部配对，支持原向、水平和垂直翻转、180 度旋转，并记录几何和像素复核证据。
- 增加固定网格候选切片、伴随文件自动发现、EasyOCR 本地识别和 B1-B5 数值审计。报告显示配对、OCR、伴随文件及数值检查的实际覆盖率；未完成的项目明确标记为未评估。
- CNN 用于候选召回，不能单独产生高级别告警。长任务支持检查点续跑，预算耗尽时保留剩余配对。

## 共享 Python 与依赖

- Windows 安装包仅携带 Python、pip 和启动必需文件。科研依赖通过签名依赖清单在线安装，所有清单条目均为必装项；单包失败时继续处理其他包并保存失败记录。
- MCP、科研引擎、本地 Skill 和 BioGenie 共用软件管理的 Python 和 site-packages。Python 设置页提供同步进度、实时安装日志、失败记录、镜像选择，以及打开共享 Python 命令行的入口。
- 安装包不包含 CNN 或 EasyOCR 模型权重；本地 OCR 缓存记录模型文件大小和 SHA-256，获取失败会在筛查结果中标明未评估。

## 使用提示

- 查重输出是供人工核对的筛查线索，不自动作学术不端结论。未完成的配对、OCR 或数值检查不会被写成“未检出问题”。
