# ZeroWall Science 8.4.14

## 环境配置

- 环境设置改为可折叠的单行分组，RMCP 排在首位；文献服务及其数据源也可按需展开。
- 增加签名环境配置读取，首次启动时从七牛云补齐缺失默认项，并保留本机变量与手动配置；安装包不包含真实变量值。
- 显示环境变量来源，并支持从当前已签名配置手动恢复。
- 增加本地默认配置导入和独立发布命令；密钥保存在忽略目录，不纳入源码和桌面安装包。

## MCP 凭据

- RMCP、SciMaster 与化工社连接可使用环境配置中的凭据，并显示对应连接状态。
- 保留现有本机凭据读取和显式设置操作。

## 资源与验收

- 更新环境配置 0.1.20、MCP 0.2.27 与 MinerU 0.1.11。
- 已配置项显示绿色，缺失项显示红色失败；保存、清除或同步后立即刷新有效配置状态。
- 修复 Host 重启时旧官方值覆盖新本地值或恢复已删除变量的问题。
- 运行环境配置签名、来源验证、本地优先、折叠界面和打包闭包检查。
