# ZeroWall Science 8.3.0

本版本完成插件目录扁平化与稳定打包复用重构。插件归档独立于桌面版本，桌面安装器只承载壳与已验证的 DSH 离线运行时。

- 插件适配源码统一位于 `plugins/`，保留上游来源与版本锁定信息。
- 8.2.1 及兼容插件归档可被 8.3.0 直接复用；桌面专属改动不会触发插件重新构建。
- SciMaster 启动器归属 MCP 插件；Python/MCP 大型环境继续独立版本化。
- 稳定打包只消费成功构建收据绑定的插件快照；失败、未完成或版本不匹配的 stage 无法激活。桌面重打包验证共享归档的大小与 SHA-256，不重建或重新归档插件。
- GUI 安装 DSH 插件遇到 pnpm store 主版本变化时，通过官方安装流程修复链接并保留 manifest、锁文件及用户选择；读取操作不会触发重装。CLI 安装的合法 DSH bundle 可导入桌面 profile，保留用户禁用、移除和固定版本设置。
- Windows 安装器与正式应用均在进程入口请求管理员权限；Host 及插件安装子进程继承该权限。安装先校验新载荷，再清理旧应用文件，并持久记录预检、清理及复制日志。用户数据目录中的插件链接使用 Windows junction。
- PPTX 使用独立生图配置，不再自动转入媒体生成。生图读取环境配置，识别名称含“生图”或“图片”的分组；媒体生成的图片模型不会覆盖这条配置。
- 生图设置同时支持普通图片接口和媒体能力目录中的图片模型；打开环境配置时刷新分组目录，显示全部可用的生图、图片分组。质量是可选参数，支持 `xhigh`、`max`，`auto` 省略质量参数；目录未列出质量时允许选择并原样发送，保留当前设置，不显示错误的“不支持质量”提示。修复不具备媒体 profile ID 的普通生图模型无法正确显示选中状态的问题。
- 安装日志与性能阶段日志按文件末尾追加，保留连续阶段、毫秒时间戳及中文内容。
- 修复 Univer 幻灯片截图忽略场景缩放与视口滚动造成的裁切；打包适配锁定上游 commit 与渲染 bundle 哈希。
- PPTX 支持并行生成整页模板，再按页规划可编辑文字、形状、连接线和原生图表/表格。编译验证 SVG 元素计划；导出核对实际 Univer 对象、文字、区域及检查结果。模板 PNG 不作为最终整页成品。
- 修复 `univer_execute` 同时传入内联代码和 `/none` 占位路径导致的调用错误，真实双来源仍拒绝。
- Python 在桌面可用后后台同步签名 core/science 依赖，按小时检查在线签名依赖，逐包安装、更新和实际导入检测；capability 仍由用户显式选择。自动任务可恢复，失败在同一固定根目录还原旧文件；固定解释器路径保持不变，安装过程不阻塞界面。
- 本版本仅构建 Windows x64；最终安装器和独立插件目录以验证收据为准。

当前插件包统一位于 `artifacts/release/plugins/`，插件清单为其中的 `plugin-packages.json`，组合快照位于 `artifacts/release/plugin-snapshots/`。更新插件时运行 `pnpm plugin:build <id>`、`pnpm plugin:pack <id>` 并生成新的已验证组件 stage；稳定桌面打包运行 `pnpm package:stable:win`，消费该快照，校验大小和 SHA-256，复用原归档。Python 回退 wheel 同样按签名清单校验、缓存并复用原发布地址，无需随桌面版本重新构建。

本地交付不等于公开发布。桌面七牛/GitHub Release、真实付费生图和 PowerPoint/WPS 最终视觉验收以另外的执行收据为准。
