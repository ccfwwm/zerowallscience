# ZeroWall Science 8.3.6

- 安装、升级直接从安装包将插件装到 `harness/profiles/web/node_modules/<插件名>` 实体目录，共享插件依赖使用 profile 内固定位置；普通启动直接复用已安装插件，目录缺失时从安装包恢复，保留固定版本、用户配置和回滚资料。
- 修复升级时保留较高版本插件却尝试加载旧 DSH 离线载体的问题：按原签名和兼容范围导入独立插件，验证当前 DSH 核心依赖，禁止旧核心随历史载体进入加载链。
- 修复 PPT 插件未打包 PPTD 规范的问题；默认快速输出图片型 PPTX，按要求输出可编辑对象，事实图片原样嵌入并保留提示词与来源。
- 统一退役插件清单，禁止 Univer、genui 重新进入初始化、导入、更新与扩展目录。
- 候选 profile 使用有界并发复制，跳过历史包备份；普通启动复用已验证布局，保留完整启动计时。
- 签名文件校验在单次验证内复用实际文件摘要，小文件直接读取并限制读取并发；每次验证仍重新核对已安装内容，安装、修复和激活之间不共享摘要。
- 安装器使用可恢复事务暂存、替换和归属差集清理，保留 Python 与未知归属文件。
- 新建或首次操作 PPT 工程时自动关联并打开演示台，子智能体工程回到所属主会话；整份工程一次加载，避免逐页重复读取。
- PPT 检查、预览和缩略图共享构建及页面缓存，只有变化或损坏页面重渲染；限制转换器并发，修复整页图片预览边缘被裁剪。
- PPT 导出、反向转换和 Office 渲染模块按需加载，启动时保留完整工具注册和演示台自动打开能力，减少 Host 首次启动解析耗时。
- 字体嵌入使用固定 ZIP 时间戳，使相同字体输入生成稳定字节；构建时精确清理旧分块，保留独立客户端资源。
- 演示工作流支持批量生图和并发检查、渲染，状态仅写入轻量索引；明确显示导出缺少的审阅、阻断项和待处理警告。
- 整页生图先逐页核验文字、布局和内容；问题图使用原图编辑后重新核验，审核绑定实际图片哈希，通过后才能导出或转换可编辑页面。
- 单插件回滚恢复独立依赖闭包，保留其他插件后续更新、禁用选择和当前布局，避免重新依赖历史目录。
- 固定版本插件的入口或依赖目录缺失时，使用安装包中的相同版本修复；已禁用、已移除插件的失效旧链接不再阻塞升级。
- 修复候选配置在插件装配完成前校验内部链接而卡在启动页的问题；装配后严格复验全部暂缺目标，同版本固定插件继续按原签名验证其依赖。
- 修复多媒体工具把空项目 ID、空任务 ID 当成错误而反复重试的问题；工具和工作台统一使用当前会话默认项目，查询任务不会触发重新生成。
- 多媒体任务增加“重新获取”和“停止本地收集”，按原任务 ID 恢复视频、音频下载；历史任务恢复进入同一后台任务记录，支持停止和再次获取，按原请求去重；上游完成与本地作品就绪分开显示，下载失败不会重复生成。
- 媒体查询和下载移出全局账本锁，后台收集支持超时、取消和分段重试，网络等待不再阻塞其他任务及会话操作；模型目录离线时仍可恢复已有任务。
- 自动轮询尊重用户的停止操作，恢复收集须由用户主动触发；多产物任务下载部分文件后，仍可停止或按原任务重新获取其余结果。
- 排队、生成中及作品尚未可取的任务持续在后台查询原任务，单次请求超时或临时网络波动后退避重试，不因总耗时或查询次数判定失败；停止操作同时中断网络和重试等待。本地收集状态与生成状态分开，避免因暂未拿到视频而重复生成。
- Host 使用可失效的本地编译缓存，工作台就绪后持久化；缓存不可用时正常启动，签名校验与插件健康检查继续执行。
- 文件查看器按首次预览加载本地渲染引擎，研究工具示例图通过版本化本地资源加载，减少首屏脚本解析；完整离线预览能力保留。

验收数据与发布收据见 artifacts/verification/8.3.6；未完成验证前不视为正式发布。
