# ZeroWall Science 8.2.0

修复插件更新后工作台误报加载超时，以及旧 Host 导航结果覆盖新一轮启动状态的问题。启动检查识别正常挂载的输入区域，包括尚未选择模型或工作区的状态；真实客户端插件错误仍会进入失败处理。插件更新在 Host 和客户端工作台均就绪后才完成激活，失败时恢复更新前的配置。启动失败或完成后停止累计计时。

没有可用工作区时，Base 插件自动在当前用户数据目录下创建并注册默认工作区，保留既有会话、已失效的项目记录、账户与模型配置。新用户无需先通过目录选择器才能进入工作台。

集成本地已经打包并适配的插件归档：Sidebar 0.26.1-zws.1、GenUI 0.12.1-zws.1、Progressive Tools 0.7.2-zws.1、Archive Manager 1.0.17-zws.1 与 Oh Story 0.1.16-zws.18。其余本地归档一并进入完整离线运行时，各插件继续独立发布和更新。

修复 Oh Story 媒体结果会话节点的数据键与定义类型不一致，导致消息正文空白和轨迹、Zotero、SSH 页面无法切换。签名插件更新将完整依赖闭包明确写入候选 profile，避免旧 profile 缺少直接依赖时向公共仓库请求本地适配版本；保留签名、健康检查和事务回滚。

插件激活及回滚在停止 Host 前先卸载旧工作台，防止旧页面继续访问已销毁的会话和语言服务。SSH 可选原生加速器按默认禁用脚本策略安装，纯 JavaScript 连接已验证；保留用户明确审计的构建选择和未审计脚本的拒绝规则。Office 本地适配包使用 0.3.7-zws.3 修订号，避免与七牛已有的不同内容同版本归档冲突。

Python 插件升级至 0.1.14。固定安装目录中的 Python 补装依赖不再被桌面版本或签名清单中的 Python 版本阻断；保留签名、架构、路径和运行健康校验，不切换或重装现有 Python 环境。

设置窗口默认宽 1040px、高不超过 820px，自适应当前窗口；支持右下角拖拽、方向键调整、Home 或「恢复默认大小」，并在本机保存尺寸。账户页面按内容容器宽度重排，修复长邮箱、费用入口和充值区域横向溢出。

集成 8.1.3 以来的 Base 更新入口、扩展中心、固定 Python 管理与环境页面改动，以及 oh-story 创作插件、AI 云平台媒体任务、素材预览和合成结果展示。各插件保持独立版本；完整离线运行时、用户自定义资源、禁用和固定版本选择继续保留。

正式构建、本地覆盖升级、真实 Electron、插件更新与回滚、七牛下载验证，以本版 verification 和 publication 收据为准。
