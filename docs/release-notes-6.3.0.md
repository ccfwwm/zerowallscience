# ZeroWall Science 6.3.0

- 全新浅色科研风安装界面，默认当前用户安装，目录选项折叠显示。
- 独立安装动画与宽厚进度区域，解压时保持动态反馈。
- 安装时自动结束目标目录中的运行进程；权限不足时保留安装界面，提供授权结束和重新检测入口。
- Windows 融合窗口，左侧红黄绿按钮支持收起到托盘、最小化及最大化；失焦时仍保持三色，并用内联 SVG 显示关闭、最小化、最大化/还原图标。
- 安装与启动页突出科研全流程、文献全流程、智能医疗、开箱即用，减少动态效果时仍保留轻量运行提示。
- 修复侧栏高度异常导致会话历史不可见、设置入口位置错乱的问题。
- 新增归档会话入口，支持搜索、查看原始内容和恢复到原工作区，重启后保持归档与恢复状态。
- 保留已有科研工作流、用户数据、主题偏好与自动更新机制。
