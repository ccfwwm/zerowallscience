# ZeroWall Science 7.0.3

本版本将 Python 作为全软件共享运行环境，MCP、科学工具与 Agent 使用同一套受管理依赖。普通设置界面显示稳定的 `Python` 目录，内部快照用于运行中的任务和失败恢复。

## 主要变化

- 旧环境迁移先在独立候选目录中合并包、检查依赖和服务，再切换入口。旧环境保留；迁移失败不会删除原环境。
- 所有受管理依赖进入同一个 `Python/Lib/site-packages`。用户安装的包保留；不兼容包明确报告。
- 启动和定时检查只发现更新。用户预览并确认后才应用依赖；中断任务须点击继续恢复。
- 七牛依赖渠道使用 Ed25519 签名清单；安装 wheel 必须匹配锁定版本和 SHA-256。软件附带本地签名清单。
- 默认使用清华 PyPI 镜像。镜像设置仅作用于本软件；不修改系统 pip 配置，也不关闭 HTTPS 证书验证。
- 镜像没有兼容 wheel 时支持从源码构建：先校验源码哈希，再使用临时 Python 和 pip 的 PEP 517 隔离环境生成 wheel，记录产物哈希并安装到候选环境。签名依赖更新必须明确授权源码归档；应用不附带这 5 个包的专用 wheel。
- 修复嵌入式 Python 的 `._pth` 导致构建子进程无法加载模块的问题；活动运行时保持不变。需要 C/C++、Rust 等原生工具链的源码包仍须具备对应编译器和开发文件，缺失时保留可操作诊断。
- 清理无效 CA 环境变量，统一 Python/pip/MCP 的证书路径，提供真实连接诊断。
- 重做 Python 设置页：紧凑状态栏、共享路径、实际健康检查、依赖计划、包搜索与高级诊断。支持窄窗口。
- Science Workbench 改为主标签页结构：常用工具固定在标签栏，其余收纳在“更多工具”，标签焦点与打开状态在刷新后重建，不再跳回脑图谱页。引擎设置改为独立对话框，配置按“项目 → 用户 → 环境变量 → 自动发现 → 默认值”解析。
- `python_environment` 提供状态、签名清单检查、同步预览、确认应用、设置、诊断和回滚。修改请求使用持久 requestId 收据，重试不会重复提交。

## 升级与使用

1. 启动后允许旧环境迁移完成；原始数据和旧 Python 目录不删除。
2. 在设置的 Python 页面检查依赖清单，预览变更，再应用更新。
3. 镜像或证书失败时使用“测试连接与证书”，保留具体诊断后再修复。
4. 包版本冲突时重新生成兼容方案；不要直接向活动环境运行 pip。

## 发布边界

本地构建、签名清单验证、实际迁移和安装包验收结果以对应发布收据为准。本文件描述版本功能，不替代运行证据。Windows wheel 清单不能用于 Linux；独立远程平台和用户配置的外部专业引擎保留各自环境。应用代码签名状态与依赖 manifest 签名分别记录。
