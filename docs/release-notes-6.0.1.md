# ZeroWall Science 6.0.1

本版本针对模型列表加载和 Markdown 文件预览进行修复，延续 6.0.0 的插件升级与科研工作流。

## 历史会话兼容

- 修复移除能力管理模块后，旧会话中的 `zerowall/capabilities/selection` 事件导致历史加载失败的问题。
- 保留旧事件、消息和原始序号，读取历史时不改写日志；继续对话使用当前 MCP 配置，不重新启用已移除的能力管理模块。

## 模型加载与切换

- 修复新建或历史会话的模型选择信息尚未到达时，一直显示“正在加载模型”的问题。模型目录就绪后先显示可选模型，会话信息到达后恢复对应选择。
- 为各模型提供方的目录发现设置独立等待上限。一家服务超时不会隐藏其他正常提供方。
- 浏览器模型目录请求超时后显示可重试的错误；重新打开菜单可以重试，提供方失败的重试会重新同步目录。
- 避免模型目录失败后持续自动刷新，保留已有模型与健康状态，健康检测与目录加载分别处理。

## 文件与附件

- 修复侧边栏预览相对路径 Markdown 文件时，图片基准目录解析错误的问题，支持 Windows 路径及中文工作区名称。
- 保留附件复制结果反馈和原生文件图标，完整重建 DSH、侧边栏及生产运行时，避免安装包混入旧插件文件。

升级会保留本地账号、配置、会话和科研项目文件。未配置凭据或无法访问的模型提供方仍需完成配置或恢复网络后使用。
