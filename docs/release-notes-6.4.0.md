# ZeroWall Science 6.4.0

- 移除 OpenCode 免费模型插件、插件注册及运行依赖；历史默认模型选择自动迁移，避免继续调用已停用的服务。
- 重启安装前核对更新版本、安装包文件名、SHA-512 和 EXE 内版本，校验失败时保留当前应用运行；普通退出不再自动安装缓存文件。
- 更新固定到当前应用目录，保留原安装范围；原位置覆盖程序资源，不再调用旧 Electron 卸载器，保留安装目录中的其他文件。只结束目标目录下的应用进程。
- PDF/文档默认启用 MinerU OCR，Precision VLM 返回的文字、图片、表格和页码进入科研技能；无需安装本地 EasyOCR/Torch。
- 兼容 MinerU v1/v2 内容清单，保留原始结果并输出标准化清单；图注和图内 OCR 分开，待补充区域可经 MinerU 再识别。
- MinerU 批次编号持久化，超时、重启后恢复查询并下载产物，避免已完成任务只返回状态而没有文件。
- 修复科研检测在 Windows 中文路径下的图片解码，记录读取失败；全局哈希匹配、图内复制和跨图片区域匹配分阶段缓存。
- 科研检测支持预算限制和检查点续跑，报告区分检测执行未完成与材料/OCR覆盖缺口；跨批次图片仍参与比较。

Windows x64 Stable 发布。托管 Python 保持 3.12.10 / 环境 1.4.0，DSH 版本不变。
