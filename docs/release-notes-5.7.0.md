# ZeroWall Science 5.7.0

本版本基于当前工作区最新代码构建 Windows x64 安装包，包含原生文献服务、环境配置和项目证据存储集成。

## 原生文献服务

- 融合 dsh-pubmed 0.4.1 的 25 个工具，通过对话检索 PubMed、Europe PMC、OpenAlex、Semantic Scholar 和 PubTator3。
- 新增项目文献保存、列表查询和 JSON、BibTeX、RIS、Mermaid 导出，导出文件登记为项目成果。
- 文献 Skill 随应用分发，通过现有能力菜单发现和调用工具。

## 环境配置

- 环境配置增加文献服务列表，提供 NCBI、Semantic Scholar、OpenAlex Key 的保存、清除、检测和官方获取地址。
- 凭据使用本机加密存储；普通开关、端点和检索源设置独立保存，下一次调用生效。
- 按服务发送凭据，支持限速、重试、取消以及服务启用控制。

## 项目文献与证据

- 保存文献标识、来源记录、概念、关系和证据，支持项目内精确标识去重及事务提交。
- 会话草稿图谱可保存到当前项目，重复提交不会重复增加图谱节点和关系。
- 研究快照升级到 V2，并保持 V1 导入兼容；现有数据库增量迁移前创建备份。

## 桌面安装包

- Windows x64 安装包版本为 5.7.0，包含打包时的当前工作区改动。
- 通过七牛云 Stable 更新渠道和 GitHub Release 分发同一 Windows x64 安装包。
