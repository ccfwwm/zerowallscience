# ZeroWall Science 7.0.0

本地构建说明，2026-09-22。此版本未发布至七牛云或 GitHub；完整科研工作台方案仍在实施和验收中，安装包存在不代表全部科研能力已经完成。

## 已实现的主要变化

- 新增六页科研工作台：研究概览、数据与资料、研究计划、专业工具、证据与结论、报告与评估。九类专业工具采用按需打开的标签页，切换保留已挂载视图。
- 增加持久研究问题、数据契约、方案冻结与修订、证据和主张记录，区分计算成功、科学适用性和人工认可；正式研究保留两个科研门禁。
- 增加 H5AD 细胞查看、基因表达、QC、圈选和导出；已用 10 万细胞进行实际性能与独立数值参考验收。
- 增加受限 TIFF/OME-TIFF/OME-Zarr 查看与原像素 ROI 测量，以及本地 Fiji/napari 打开、版本化标注回传和冲突保留。OME-Zarr 已通过 10 GiB 分块数据的按平面读取测试。
- 增加五类 Fiji 实验的固定执行路径、质控叠加与可追踪产物，包括 Western blot、划痕、克隆、菌落和成管分析。
- 增加 OpenSlide 金字塔 HE 查看、物理测量、区域导出；StarDist CPU 分块分割使用独立按需环境，其验收单独记录。
- 增加本地 Mol* 分子结构查看、PDB/mmCIF/SDF、测距、表面和截图导出，以及通过现有 rmcp 的 Vina 对接流程。
- 增加 FASTA/GenBank 序列图谱、注释、限定PCR/Gibson/GoldenGate模拟，AB1/SCF 峰图、裁剪和参考比对，FCS 分块处理、补偿、层级门控与限定 GatingML 2.0 双向交换。
- 增加1–9面板科研画布、轴/图例/配色编辑和四格式导出，以及 BrainGlobe 工作流入口；细节能力和未完成项目以实施验收记录为准。
- 改造 NHANES 数据契约与权重校验，接入固定遗传分析和组学工作流；系统提示词、角色规范、技能来源和策略哈希纳入研究记录。
- 统一 Windows Host 内的 Sharp 版本，修复混用 libvips 导致的分子截图导出失败。

## 已验证与待验收边界

已完成源码回归、实际引擎和部分远程任务验证，以及打包后的 Electron 启动、工作台研究恢复和分子显示/导出测试。安装器的真实安装/升级、全部九类工具在安装包中的完整交互、所有独立引擎包和完整方案验收仍须单独完成。

当前不承诺完整 FlowJo 兼容、自动引物设计、任意组装条件与固定基因组脱靶搜索、全切片 HE 批处理、完整图像 XY 瓦片分析、出版级画布编辑或全部脑配准质量验证。相关界面和报告应保留支持范围及失败原因。

“肥胖—脱发”目前仅有实际数据目录侦察和可行性记录；尚未形成通过两个人工门禁的医学结论。12 项任务、四条件共 48 次先导对照尚未全部实际运行，不能宣称平台优于基线。

详细证据与剩余工作见 `docs/science-7.0.0-implementation-status.md`。引擎包、模型许可和离线安装见 `docs/science-engine-packages.md`。本地安装包版本为 7.0.0，未加 beta 后缀。
