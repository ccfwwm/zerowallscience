# ZeroWall Science 8.4.15

## 资源安装与更新

- 新增的已验证插件、Skills 和 MCP 资源显示安装按钮，已移除的签名插件可重新安装；下载和安装由用户点击触发。
- 修复插件更新时嵌套 DSH 命令重复获取桌面事务锁，误报 `PLUGIN_TRANSACTION_BUSY` 的问题；嵌套命令验证事务身份并复用父事务，保留健康检查和失败恢复。
- 修复 MCP 目录资源 ID 与服务器名称不一致时无法安装的问题。

## 任务状态

- 资源操作按队列执行，后续任务显示等待状态，前一任务完成或失败后继续。
- 操作记录优先显示全部运行中、排队和待重启任务，避免被最近历史记录挤出；保留执行日志、进度及最终状态。
- 任务落盘与状态通知按顺序写入，避免并发进度覆盖完成记录。

## 集成

- 扩展中心更新至 0.1.18；桌面、Skills、MCP、Python 和其他插件保留各自独立版本。
