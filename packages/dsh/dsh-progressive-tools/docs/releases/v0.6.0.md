# v0.6.0 — Host runtime 0.1.7-rc.2

This release accepts DeepSeek Harness `0.1.7-rc.2` and no longer accepts
`0.1.5-rc.1`. Core peers are pinned to the tested prerelease. Cordis is
`~4.0.4` and the validator is `~3.18.4`.

Discovery initializes on `agent/created`. Resume reads the current tool-result
message shape and still accepts older tool-result content blocks. PTC tests
use `ctx.ptcRuntime`.

## Install

```sh
dsh plugin --profile web add npm:@everclear077/dsh-progressive-tools@0.6.0
```

```sh
npm install @everclear077/dsh-progressive-tools@0.6.0 --registry https://registry.npmjs.org
```

`0.5.1` remains installable only on host `0.1.5-rc.1`.
