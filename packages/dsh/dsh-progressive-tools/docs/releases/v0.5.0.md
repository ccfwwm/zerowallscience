# v0.5.0 — Smaller discovery and dispatch results

This release keeps the host baseline at `0.1.5-rc.1`. Default search and
dispatch results no longer repeat the same tool body or the cumulative
discovery list. Optional budgets and profiles stay off unless configured.

## Changes

- Search results use `dsh-progressive-tools/v3`. An exact name returns that
  tool only. Each family member table appears once. A definition still present
  in derived history returns a short notice unless `reload` is set.
- `tool_dispatch` returns `dsh-progressive-tools/dispatch-v2`:
  `{ protocol, tool, value }`. Rendered content is not copied into that value.
  `legacyResults: true` restores the previous envelopes.
- `estimatedSavedTokens` remains a metadata alias of `omittedDefinitionTokens`.
  It estimates definitions omitted from the top-level tool list. It is not a
  bill and not a net task saving.
- Optional `resultBudget` shortens direct dispatch text and the model-facing
  `run_code` text. The program value stays intact. `tool_result_read` reads
  the stored original.
- Optional `profile: coding`, `profile: auto`, and `autoloadMaxTools` can widen
  the frozen surface. The defaults do not.
- Filesystem tools stay on the default stable surface. Default `maxResults`
  is `2`.

## Validation

- 73 tests pass across eight suites.
- Type checking, lint, build, and package validation pass.
- No peer dependency conflicts in the release validation environment.

PTC tests use the real host dispatch bridge with a binding runtime fixture.
They do not run language interpreters. No paid task-cost comparison is claimed.
The host tool schema still has no public deferred-tool field.

## Upgrade

Stay on host runtime `0.1.5-rc.1`. Install tag `v0.5.0` or npm package
`dsh-progressive-tools@0.5.0`. Programs that read dispatch `.content` need
`legacyResults: true` or a change to read `.value`. Back up sessions before
upgrading. The plugin does not migrate host session files.

See [migration](../migration.md) and [configuration](../configuration.md).
