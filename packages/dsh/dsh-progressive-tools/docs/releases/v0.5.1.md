# v0.5.1 — Scoped npm package

The unscoped npm name `dsh-progressive-tools` is already published by another
account. This release publishes the same plugin as
`@everclear077/dsh-progressive-tools`. Behavior and the host baseline
`0.1.5-rc.1` are unchanged from `0.5.0`.

## Upgrade

Install tag `v0.5.1`, or:

```sh
npm install @everclear077/dsh-progressive-tools@0.5.1 --registry https://registry.npmjs.org
```

`v0.5.0` remains the previous Git tag. It is not republished under the
unscoped npm name.
