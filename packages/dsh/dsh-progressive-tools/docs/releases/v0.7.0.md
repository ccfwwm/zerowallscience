# v0.7.0 — Host runtime 0.2.0-rc.1

This release accepts DeepSeek Harness `0.2.0-rc.1` and no longer accepts
`0.1.7-rc.2`. Core peers are pinned to the tested prerelease. Cordis stays
`~4.0.4` and the validator stays `~3.18.4`.

Host tool schemas may include `deferLoading`. stable-proxy still removes
deferred catalog tools from the assembled request. A tool that is already on
the stable surface keeps the flag. Routes without tool updates strip the flag
and send the full schema, so the plugin does not use it as the discovery path.

## Install

```sh
dsh plugin --profile web add npm:@everclear077/dsh-progressive-tools@0.7.0
```

```sh
npm install @everclear077/dsh-progressive-tools@0.7.0 --registry https://registry.npmjs.org
```

`0.6.0` remains installable only on host `0.1.7-rc.2`.
