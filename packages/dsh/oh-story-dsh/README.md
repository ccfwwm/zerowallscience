# @oh-story/dsh — 多媒体创作

通过聊天描述需求即可生成图片、视频和音乐。右侧原生工作台用于模型设置、进度与作品预览，无需填写项目表单。支持改图、遮罩、异步恢复、素材导入，以及带字幕、音乐和导入旁白的宣传片合成。配音模型未提供时显示暂不可用。

登录 AI 云平台自动发现“图片音频视频分组”，凭据留在 Host。保留有效模型选择；选择失效时要求用户重新选择。不会修改聊天模型、协议或推理参数。模型工具支持准备、生成、导入、修改、查询与收集。用户明确要求生成时直接执行，后台校验费用及账号权限，不增加费用确认。讨论方案及修改文案不会提交生成；重复调用沿用原请求。首次未配置模型时自动选可用模型。

新项目位于 media-projects/<projectId>/。普通聊天保持原布局，媒体工作台可收起。分镜列表可编辑素材、时长、顺序、裁切和字幕；支持图片推进/拉远、音乐音量与淡入淡出、导入旁白、片头片尾。默认导出1080p、30fps、MP4 H.264/AAC。保留原始素材，以实际时长校验成片。

本地合成使用 zerowallPython 固定根和执行租约，需FFmpeg、FFprobe、libass、libx264、AAC；依赖缺失时逐项显示。不会回退到PATH Python或自动下载依赖。

仅提供本地测试包，不上传七牛或GitHub，不部署Sub2API。安装、验签、候选profile健康、原子激活和回滚由既有资源管理器处理。任务中断后恢复原请求；停止等待不等于服务端取消或退款，状态不确定时显示待核查。历史任务仅允许查询和下载。

小说、游戏、短剧、解说页面及相应工具、Skills、Roles、Hooks和资源已退出运行与发布包。用户历史项目文件保留，不自动迁移或改写。
