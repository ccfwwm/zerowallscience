# MinerU 文档解析

远程解析文档 URL、工作区文件和已核验的会话附件。自动模式有 Token 时使用 Precision，无 Token 时使用轻量 Agent。可从启动环境读取 MINERU_API_TOKEN，或在设置中保存 Token；已保存设置优先。

插件自带可检索的 mineru-document-parser 技能，支持 Precision 结构化产物、选页、可选页码锚点、真正批量处理和长 PDF 续跑。科研工作流要求 Precision 和 OCR。两种模式均向 MinerU 发送文档。

通过插件管理器更新，无需更新桌面安装包。参见[用法与限制](README.zh.md)。
