# @zerowall/research-store

Research storage

Share the SQLite research store between research and MCP plugins. Consumers provide a database path and own closing the store. This package is a library and starts no application.

Build with pnpm run zerowall:build and inspect archives with pnpm run zerowall:pack at the repository root. The tested baseline is Node.js 24.9 or later and DSH 0.2.2-rc.1.
