# @zerowall/dsh-plugin-python

Managed Python

Inspect and manage the Python runtime from the plugin detail page or Settings. Runtime selection and installed packages stay in their existing management directories. Opening the page reads inventory; installation is an explicit action.

Build with pnpm run zerowall:build and inspect archives with pnpm run zerowall:pack at the repository root. The tested baseline is Node.js 24.9 or later and DSH 0.2.2-rc.1.
