# Python 运行环境

[English](plugin-detail.md) | 中文

## 摘要

DSH 提供 Python 3.12.14。uv 0.13.7 启动时自动准备锁定的核心依赖。Desktop 提供离线 wheel 目录，npm 安装从配置的索引下载同一组哈希锁定的软件包。可选 Skill 主题使用独立环境。

## 配置

在下方查看启动准备状态，失败后可重试；刷新只读取状态。明确修改依赖时创建并验证新环境代际，运行中的消费者继续使用原代际。路径通过环境变量或 profile 提供，不迁移旧 Python 目录。独立 npm 安装未获得 DSH 解释器时，uv 可下载资源清单锁定的准确 Python 版本。

确认后的软件包索引会在重新启动后保留。请使用不含凭据、查询参数和片段的 HTTPS URL。准备失败时保留当前代际；读取尚未准备的 Skill 依赖时，需要明确执行准备操作。

设置 `ZEROWALL_PYTHON_WHEELHOUSE` 为绝对目录可离线准备核心依赖；插件逐个校验清单中的 wheel，错误的明确配置会停止准备，不会退回联网安装。未指定目录且包内没有 wheel 时，npm 首次准备需要联网。
