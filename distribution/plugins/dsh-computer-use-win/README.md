# Windows computer use for ZeroWall Science

English | [中文](README.zh.md)

Provides Windows desktop observation and input. Enable the plugin in the Desktop plugin manager. If a write times out after dispatch, check the target document for the intended text before retrying.

This distribution is based on [dsh-computer-use-win v0.6.4](https://github.com/Yu-tao-Li/dsh-computer-use-win/tree/v0.6.4) by Yu-tao-Li under the MIT license. The upstream project documents the Windows automation tools, settings, and limitations.
