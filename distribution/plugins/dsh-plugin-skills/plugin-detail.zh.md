# 技能管理

在一个目录中查看插件使用说明、整理后的科研工作流与用户导入技能。停用和被同名项覆盖的条目仍可查看。初始启用 12 个核心工作流；其他内置工作流可在任务需要时自动启用。用户可通过 `skills_manage` 搜索，也可使用开关设置全局或工作区可用状态。手工关闭始终优先。

开关默认管理所有工作区；需要局部覆盖时选择具体工作区。文件夹、ZIP、Markdown 和公开 GitHub 来源先预览；同名冲突需要选择是否替换。导入项保持停用，导入期间不会运行脚本或安装软件包。只有允许模型调用的内置工作流支持自动启用。

可选工作流启用前会准备需要的 Python 依赖。移除导入项时取消注册，并保留文件与备份信息。插件使用说明随所属插件管理，标准 DSH 和 Claude 会话采用同一启停策略。
