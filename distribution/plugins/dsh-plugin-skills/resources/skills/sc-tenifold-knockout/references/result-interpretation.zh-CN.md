# 结果解释规范

## 三层结论

1. **R 统计观察**：只描述输出中存在的效应量、方向、调整后 P 值、网络距离和稳定性。
2. **机制证据**：只引用 Bio Tools MCP 或公开数据库返回的 GO、Reactome、UniProt、PubMed 记录。
3. **待验证假设**：提出 CRISPRi、siRNA、药理抑制、rescue 和读出建议，并明确尚未进行真实实验。

如果没有 `diff-regulation.tsv`、稳定性结果或机制来源，必须写明“无法判断”，不能用通用生物学知识补齐。

## 改变原因

报告分别说明：哪些基因改变、改变的统计依据、哪些通路与其相关、证据强度和替代解释。不要把网络扰动写成确定因果关系，也不要把虚拟敲除写成真实细胞实验。

## 图表最低要求

报告应链接 QC、细胞组成、目标表达、WT/KO 网络、差异调控、火山图、稳定性和阴性对照图；同时提供显示每个阶段状态的 `process-diagram.mmd`。
