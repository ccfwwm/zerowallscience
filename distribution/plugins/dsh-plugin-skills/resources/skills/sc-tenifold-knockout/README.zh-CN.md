# scTenifoldKnk 中文使用说明

## 这项技能做什么

它把公开单细胞数据、远程 R 分析、网络扰动解释、图表、文章和实验验证建议串成一个可追溯流程。用户可以从一句研究问题开始，不必先上传矩阵。

## 如何开始

直接描述目标即可：`虚拟敲除 HSPA1A，研究非肿瘤肺泡巨噬细胞。`

如果没有目标基因，提供参考基因或研究主题，系统会查询公开基因、文献和表达证据后给出候选。候选建议不是最终结论，必须显示来源、理由和置信度。

## 结果如何阅读

- 统计观察：R MCP 实际算出的 `FC`、`Z`、`p.adj`、网络距离和稳定性。
- 机制证据：GO、Reactome、UniProt、PubMed 对观察结果的支持。
- 待验证假设：可以设计实验验证，但不能写成已经发生的真实敲除。

每个结论都应能追溯到 study ID、数据集 accession、输入 checksum、R 版本、参数和 run ID。

## 运行限制

所有生产 R 操作都在远程 R MCP 执行。若远程环境未安装 `scTenifoldKnk`，流程会停止并显示 `missing_runtime`。大数据下载、FASTQ/SRA、长时间运行和可能收费的计算需要用户确认。湿实验只生成协议，不自动执行。
