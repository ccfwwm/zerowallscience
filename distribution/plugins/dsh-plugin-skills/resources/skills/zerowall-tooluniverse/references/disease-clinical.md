# 疾病与临床

检索词：ClinicalTrials、OpenTargets、EFO、MONDO、ClinVar。固定疾病本体和人群、干预、比较、结局。临床试验以 NCT ID 核对招募状态、阶段、更新时间与原始注册页；状态可能改变，应记录查询时间。

按 NCT ID 搜索/describe 精确试验详情工具；NCT04280705 为示例。靶点关联通过 OpenTargets 的稳定 Ensembl ID 查询，例如 TP53 的 ENSG00000141510。关联分数、遗传证据和临床结局分别保存，不把数据库关联描述为临床疗效，也不将工具输出作为个体诊断或用药决策。

固定上游的相关研究任务可按需从[工作流导航](upstream/disease-clinical.md)选择。每个摘要保留原文链接、摘要 SHA-256、阶段结构和固定 SDK 工具候选，执行仍以实时 schema 为准。
