# Method fit review

Extract the actual design, outcome type, group count, sample size, repeated/paired relationships, distribution assumptions, tested model and multiplicity correction from the supplied plan, methods and code. Cite their source locations and leave missing fields unknown.

Review whether the observed unit matches the experimental unit, the model represents repeated observations, distributional assumptions are supported, effect estimates include uncertainty, and multiplicity or model selection is addressed. MR additionally needs instrument strength, ancestry/build, harmonization and overlap checks; coloc needs complete-region information and explicit causal assumptions.

Record each finding as a reasoned review with its evidence and limitation. This workflow has no automatic deterministic verdict service. Missing metadata is insufficient information; no listed issue does not certify scientific validity.
