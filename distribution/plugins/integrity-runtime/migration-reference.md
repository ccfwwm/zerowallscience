# @zerowall/integrity-runtime

Resource integrity helpers

Verify signed resource manifests and streamed downloads. This package is a library with no DSH profile layer or application entry point.

Build with pnpm run zerowall:build and inspect archives with pnpm run zerowall:pack at the repository root. The tested baseline is Node.js 24.9 or later and DSH 0.2.2-rc.1.
