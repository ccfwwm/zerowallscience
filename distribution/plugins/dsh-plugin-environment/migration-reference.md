# @zerowall/dsh-plugin-environment

Environment and image settings

Set image models, quality and context budgets in Settings or in the Image create and PPT create plugin pages. Secret environment values stay in the Host credential store. Opening or refreshing settings does not save a selection.

Build with pnpm run zerowall:build and inspect archives with pnpm run zerowall:pack at the repository root. The tested baseline is Node.js 24.9 or later and DSH 0.2.2-rc.1.
