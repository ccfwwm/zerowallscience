# @zerowall/dsh-plugin-environment

启动时先恢复安全存储，再校验七牛云签名配置并补全缺失变量。自定义值、进程环境变量和用户删除记录均保留。设置页展示同步状态，并提供只补全缺失值的重试；“恢复官方默认”仍需明确确认替换。网络或签名失败不改变本地配置。`ready()` 等待本地恢复及首次同步尝试，离线时正常完成；安全存储失败则拒绝完成，阻止依赖服务使用未知凭据。

## 摘要

在插件详情或设置页配置环境变量和上下文预算，生图设置归属生图插件。凭据保存在 Host 安全存储；打开或刷新页面只读取配置。

对话输入栏提供 32k–1m 上下文预算，默认 300k。达到 90% 时，Host 精简工具结果并压缩较早对话，同时为模型输出预留空间。按会话读取和保存依赖实时 Agent 注册表；调整写入 Session 日志。保存未确认时保留最后确认的显示值，并提示重新打开对话核对实际预算。

## 使用

ZeroWall Desktop 根据安装清单选择此包。在插件页检查状态和插件提供的配置。验证基线为 DSH 0.2.2-rc.1 和 Node.js 24.9 或更新版本。更新时保留已有配置与数据。

详细工作流及历史平台要求见[保留的迁移参考](migration-reference.md)。当前依赖版本以包清单为准。

## 开发

在仓库根目录构建并检查压缩包：

```sh
pnpm run zerowall:build
pnpm run zerowall:pack
```
